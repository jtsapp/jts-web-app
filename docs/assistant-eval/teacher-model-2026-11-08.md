# Луна — учитель английского на Sonnet 5.5 (08.11.2026)

Продолжение `teacher-quality-2026-11-08-round2.md`: указаниями у вопроса Haiku 5.5 без мышления упёрлась в 85 % при
цели ТЗ 95 % (8.3а), больше половины провалов — неверный факт в объяснении. Владелец разрешил для ответов учителя
отдельную сильную модель (ТЗ 8.5: «для свободного чата и объяснений — сильная модель»).

## Что сделано

- `src/lib/assistant/model.js` — модель хода. Вопрос учителю — `ASSISTANT_TEACHER_MODEL` (по умолчанию
  `claude-sonnet-5-5`), остальное — `ASSISTANT_MODEL` (Haiku 5.5). Признак вопроса учителю — тот же, что включает
  шаблоны учителя (`turnHints.isTeacherQuestion`, вынесен из `questionHints` без изменений). Haiku остаётся на:
  служебных ходах (первая реплика, позывной, «Подсказать?», ступени подсказки, события «Луна пишет первой»), на экране
  с непроверенным заданием (там Луна только подсказывает — эту дисциплину мерили на Haiku) и в звонке Луне.
- `src/lib/anthropic.js` — Sonnet 5.5 не принимает `thinking: disabled` (400): ей уходит `between_tools` (самое низкое
  мышление; без тулов — без мышления вовсе) и `effort` вызывающего, по умолчанию `low`. Префилла у неё тоже нет.
- Роут: Sonnet упала (свой лимит запросов, сбой) или кончила пустым до первого слова (отказ классификатора) — тот же
  ход на Haiku. Ученик получает ответ, а не «не удалось ответить».
- Откат без правки кода: `ASSISTANT_TEACHER_MODEL=claude-haiku-5-5` (и `ASSISTANT_TEACHER_EFFORT`, `low | medium |
  high`) — переменные заведены в `compose-app.yaml`.
- Прогон качества выбирает модель тем же `pickAssistantModel`; флаги `--teacher-model`, `--teacher-effort`,
  `--model-all`; в строке ответа — модель, время до первых слов, ответ целиком, usage и цена.

  «объяснение плотнее, чем нужно для A2». Остальные кейсы раздела 10 — справка по сайту, они на Haiku и не изменились.

## Скорость

Время до первых слов — как отметка `model` в Server-Timing роута (пока не ясно, метка «не по теме» это или ответ),
с этой машины до API; ответы набора учителя.

| | Первые слова p50 / p90 | Первая фраза голоса ≈ p50 / p90 | Ответ целиком p50 / p90 | Вывод |
|---|---|---|---|---|
| Haiku 5.5 (low, без мышления) | 631 / 804 мс | 765 / 943 мс | 2,0 / 3,2 с | 187 ток/с |
| Sonnet 5.5 (low, between_tools) | 791 / 1063 мс | 1010 / 1276 мс | 3,4 / 4,6 с | 120 ток/с |
| Разница | +160 / +260 мс | +245 / +335 мс | +1,3 / +1,4 с | |

«Первая фраза голоса» — первые слова плюс ~25 токенов (первая фраза озвучки ≤ 90 символов, `speechChunks.js`) по
скорости вывода этого же ответа.

## Цена ответа

Системный промпт — 34,9 тыс. токенов (база знаний + правила), ход ученика с профилем — ≈ 1,9 тыс. Кэш промпта у
каждой модели свой и живёт 5 минут.

| | Тёплый кэш | Промах кэша системного промпта |
|---|---|---|
| Haiku 5.5 | 0,07 ¢ | 0,5 ¢ |
| Sonnet 5.5, прогон | 1,2 ¢ (среднее 665 ответов) | 10,1 ¢ (3 замера) |
| Sonnet 5.5, прод (оценка) | 1,5–2 ¢: контекст ученика в проде свой у каждого и пишется в кэш (в прогоне профиль один) | ≈ 10–11 ¢ |

Главное: Sonnet в 15–20 раз дороже Haiku за тёплый ответ, а промах её кэша — ещё ×7. Вопросы учителю — малая часть
потока, и если они приходят реже раза в 5 минут (на каждую из четырёх версий промпта: ru/kk × с токенами и без), почти
каждый ответ — промах, ≈ 10 ¢. Сто таких вопросов в день — ≈ 10 $ в день. Если так и выйдет по логам (`llm_cost`,
`model: claude-sonnet-5-5`, `cacheReadTokens` ≈ 0), следующий шаг — часовой кэш системного промпта для Sonnet
(`ttl: "1h"`, запись ×2): он окупается уже с двух вопросов учителю в час. Не сделано: без потока прода не посчитать.

## Звонок Луне — Haiku

В звонке первую фразу ждут вживую, а Sonnet даёт её на ≈ 0,25 с (p50) — 0,33 с (p90) позже. Кроме того, звонок
спрашивает роут черновиками (упреждающая генерация, до трёх попыток на ход) — на Sonnet это до трёх платных ответов
по 1,5–10 ¢ на одну реплику. Поэтому реплика звонка (`call` в теле, живая комната) идёт на Haiku при любом вопросе.
Голосовой вопрос в окне (микрофон → ответ голосом) — на модели вопроса, то есть учителю на Sonnet: +0,25 с к первой
фразе там при «Думаю…» на экране; если это заметят — та же развилка по `parsed.voice` в `model.js`.

## Как повторить

```bash
node scripts/assistant-eval/run.js --phase haiku-base --set teacher --n 2 --teacher-model claude-haiku-5-5
node scripts/assistant-eval/run.js --phase sonnet-low --set teacher --n 3
node scripts/assistant-eval/run.js --phase sonnet-med --set teacher --n 2 --teacher-effort medium
node scripts/assistant-eval/run.js --phase miss-sonnet --set teacher --only e19,h01,h06,h11,h23,h24 --n 3 --model-all claude-sonnet-5-5
node scripts/assistant-eval/run.js --phase luna-l14 --set luna --only L14 --n 3
```

Стоимость всех прогонов этого замера ≈ 13 $ (ответы Sonnet ≈ 8 $, судья ≈ 4,5 $, Haiku ≈ 0,4 $).
