Как ставится итог:
- **Прошёл** — проверки экрана зелёные, а зонд зачёл не меньше 2 ответов из 3 по главному критерию кейса. Замечания судьи — в
  примечании.
- **Упал** — красная проверка или зонд зачёл 0–1 из 3.
- **Частично** — часть кейса сделана и проверена, часть не сделана.
- **Решение владельца** — не делаем по решению владельца.
