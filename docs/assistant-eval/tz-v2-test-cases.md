Цель ТЗ ≥ 95 % верных не достигнута. Остаток — в основном знания самой Haiku 5.5, а не указания: какая «d» не читается в
Wednesday, «I like to read» объявлено ошибкой, «I missed you» вместо «I miss you», выдуманные «частые ошибки», в
казахском — латиница внутри слов, турецкое «aslında», русские слова. Владелец решил оставить Haiku 5.5 (решение 1), а
ТЗ 8.3а предлагает справку по грамматике из базы программы (RAG) — её нет; это следующий шаг, если 95 % нужны.
