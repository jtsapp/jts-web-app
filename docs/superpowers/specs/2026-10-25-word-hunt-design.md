25.10.2026. Новый раздел «Практики», вкладка «Чтение». Делается тремя параллельными сессиями (бэкенд, web-admin,

## Что это

Прототип методиста `C:\Users\nural\Downloads\jtswordhunt.html` (копия `Word hunt (1).html`, 11,7 МБ, sha256
`7f236f25c9a8e916…`). Две игры над словарём курса: **кроссворд** (три шага-«луны» на урок, подсказки по
CEFR-политике) и **поиск слов** (три сложности + «на время»). Карта: миры = уровни A0–B2 и 16 «станций»
лексики по специальности → секторы = юниты → планеты = урок (≤ 12 слов на планету). Награды, серия дней,
«кометы» (слова, где понадобилась подсказка), маскоты Dexter/Luna/Aizere/Spark, языки RU/KZ.

Устройство файла (строки — для ориентира, полагаться на них нельзя):

| что | где | размер |
|---|---|---|
| стили + 26 картинок дизайна (hero, 6 зон, 4 маскота, 15 спрайтов) — `url(data:image/webp)` в CSS | `<style>` | ~0,9 МБ |

| `var AUD={<id атома>: "data:audio/mpeg;base64,…"};` — студийные записи слов A0 | там же | 426 шт., 2 МБ |
| `var PICS={<id карточки>: "data:image/webp;base64,…"};` — картинки A0 без подписи | там же | 73 шт., 2,1 МБ |

| движок: `XWCore` (кроссворд), `WSCore` (поиск), `LXClue` (политика подсказок), `LX` (оболочка), игры xw/ws | 6 `<script>` после данных | ~3 000 строк |

Все пять литералов данных — однострочный JSON после `var X=` до `;`, все в ОДНОМ `<script>` (тот, где `var DB=`).
Настоящий файл: 21 область (5 уровней + 16 специальностей), 11 241 атом, 426 записей (все ключи — id атомов),
73 картинки (все ключи — id карточек), 11 238 записей CLUEQ (все ключи — `область|id атома`). Три id атома
повторяются внутри одного урока (дефис/пробел: `closed-loop control`) — движок склеивает их сам, это не брак.

## Решения (допущения — владелец может переиграть)

- **Д1. Источник** — прототип заливают ЦЕЛИКОМ в web-admin, как Prepositions World. Словарь в нём — копия
  каталога «Словаря» на момент аудита CLUEQ; отдельного источника правды для слов не заводим, с
  `/mobile/vocab-catalog` не связываем (аудит подсказок привязан к этой копии).
- **Д2. Монет нет** — в прототипе их нет («звёзды» = собранные слова). Квоты и домашки нет.
- **Д3. Вход обязателен** (`Bearer`), как у Prepositions/Cartoons. Гость видит приглашение войти.
- **Д4. Заливают ADMIN и CONTENT_MANAGER** (как «Грамматика · игры»).
- **Д5. Полный прототип в git не кладём** (11,7 МБ): сайт держит урезанную фикстуру для оракула,
  картинки дизайна — файлами в `public/`.
- **Д6. Озвучка** — запись `aud` (A0), иначе Soniox через `/api/tts` (правило проекта: голос браузера —
  только запасной по `onFail`).
- **Д7. Язык** — интерфейса приложения: `kk` → KZ, иначе RU (у прототипа только RU/KZ). Свой переключатель
  RU/KZ прототипа убираем, как в других портах.
- **Д8. Плитка** — вкладка «Чтение» Практики, перед «Аркадой» (сказки остаются последними).

## Бэкенд (модуль `wordhunt`, образец — `prepositions`, `docs/practice/PREPOSITIONS.md`)

### Разбор файла

Читает пять литералов как JSON. Хэш движка — sha256 текстов всех `<style>` и всех `<script>` без `src`,
кроме скрипта данных (где `var DB=`), склеенных через `\n`, переводы строк `\n`. Не совпал с
`wordhunt.engine-sha` (значение от настоящего файла — печатает тест) — предупреждение «другой движок:
правки движка на сайт попадают только PR сайта».

**Ошибки** (вся заливка отклоняется, ответ 400 со списком): нет любого из `DB`/`FIELDS`/`AUD`/`PICS`/`CLUEQ`
или не JSON; `DB.levels` не массив или пуст; у первого уровня нет ни одного урока с атомами (кнопка
«Начать» ведёт туда); область без `units`/`lessons`; урок без массивов `cards`/`atoms`; атом без `id`;
`AUD` не `data:audio/mpeg;base64`; `PICS` не `data:image/webp;base64`; файл > 20 МБ после декодирования.

**Предупреждения** (заливка проходит, список виден в админке): уровень из `levels` или станция из `FIELDS`
без своей области в `DB` (движок их молча прячет); `cat` станции не из tech/biz/health/science; атом с
пустым `en` (движок пропускает); юнит ссылается на несуществующий урок; повтор id атома в РАЗНЫХ уроках
области; ключ `AUD` — не id атома; ключ `PICS` — не id карточки; ключ `CLUEQ` — не `область|id атома` или
значение не `^(A0|A1|A2|B1|B2|C1)…`; другой движок. Настоящий файл: 0 ошибок, 0 предупреждений.

### Что пишется

Как у предлогов: одна заливка за раз (вторая — 409); медиа `practice/word-hunt/<sha24>.mp3|webp`
(`PracticeMediaStorage`, immutable, только новые); строка релиза (таблица `word_hunt_releases`: номер,
кто, когда, имя и размер файла, `engine_sha`, счётчики, предупреждения); `word-hunt/current/bundle.json`;
сброс кэша ученика; удаление медиа, на которые не ссылаются ни новый, ни ПРЕДЫДУЩИЙ бандл. Номер миграции
сверять ПЕРЕД мержем (параллельно идёт «Скорочтение»), а не при создании PR.

### Бандл (ученику — ровно это)

```json
{
  "release": 3,
  "uploadedAt": "2026-10-25T15:00:00Z",
  "engineSha": "…",
  "db":     { "levels": [ … ], "A0": { … }, "F:business": { … } },
  "fields": [ … ],
  "clueq":  { "A0|a1_like": "A011-0" },
  "aud":    { "a10_big": "https://files-dev.justtostudy.kz/…/practice/word-hunt/<sha24>.mp3" },
  "pics":   { "c1_like": "https://files-dev.justtostudy.kz/…/practice/word-hunt/<sha24>.webp" }
}
```

`db`, `fields`, `clueq` — как в файле, байт в байт по содержанию (ничего не переименовывать и не
выбрасывать); `aud`, `pics` — те же ключи, data-URI заменены публичными ссылками бакета.

### Ручки

| ручка | кто | ответ |
|---|---|---|
| `POST /admin/word-hunt/upload` (multipart `file`, .html) | ADMIN, CONTENT_MANAGER | 200 `Release`; 400 `{errors: [строка], warnings: [строка]}`; 409 «загрузка уже идёт» |
| `GET /admin/word-hunt/release` | ADMIN, CONTENT_MANAGER | 200 `Release` текущего; 404, если не загружали |
| `GET /mobile/word-hunt` | любой с `Bearer` | 200 бандл телом (у бакета нет CORS); `ETag: "wh-<release>"`, `If-None-Match` → 304; 404 «Word Hunt ещё не загружен» |

`Release` = `{release, uploadedAt, uploadedBy, fileName, fileSize, engineSha, engineKnown, counts: {levels,
fields, lessons, atoms, audio, pics, clueq}, warnings: [строка]}` (`levels` — уровни A0–B2 с областью,
`fields` — станции с областью). Ошибки и предупреждения — по-русски, с местом: «A1 · урок 5 · атом a5_x: …».

`/admin/**` в `SecurityConfig` режет не-ADMIN раньше `@PreAuthorize` — добавить `authenticated()` для
`/admin/word-hunt/**` и WebMvc-тест на настоящем конфиге (так чинили «Грамматику · игры»). Бандл ~6,5 МБ
JSON — на проводе обязан идти сжатым (держать в памяти gzip-копию или проверить `server.compression`); в
таймаут прокси перед бэкендом (прод — Cloudflare 100 с) заливка 11,7 МБ и ~500 файлов должна укладываться.

## Админка (web-admin)

«Практика и тесты» → вкладка **Word Hunt** (рядом с Prepositions World / Cartoon World / «Грамматика · игры»),
видна ADMIN и CONTENT_MANAGER. Экран: текущий релиз (номер, кто/когда, файл, счётчики, предупреждения,
«движок известен / другой движок»), «Загрузить прототип» (выбор .html, прогресс отправки, на 400 — список
ошибок и предупреждений, на 409 — «уже идёт загрузка»), пустое состояние до первой заливки. Тексты
ru/kk/en в словаре админки. Образец — экран Prepositions World.

## Сайт (jts-web-app)

- Экран `?screen=wordhunt` (`src/screens/WordHuntPage.jsx`), движок — `src/practice/wordhunt/engine.js`:
  скрипты прототипа почти дословно в Shadow DOM, `mountWordHunt(root, cfg) → destroy` (образец —
  `src/practice/prepositions/`). Отличия от прототипа — списком в шапке файла.
- Данные — `getWordHunt(token)` в `src/api.js` → `GET /mobile/word-hunt`; 404 — «Раздел готовится».
- Картинки дизайна (26 webp из CSS) — `public/practice/wordhunt/img/`, выгружает
  `scripts/wordhunt/extract-assets.js` из прототипа; CSS ссылается на файлы.
- Шрифты — сайта (`inherit`), казахский — Inter (`kkFont.test.js`).
- Звук: `aud[id атома]` через `playUrl`, иначе `/api/tts` (`ttsUrl`), по `onFail` — голос устройства.
  Колокольчик верного ответа (Web Audio) — как в прототипе.
- Прогресс — модуль синка `wordhunt`, ключ прототипа `jts_lexiverse_v1`, сведение merge: собранное
  слово и пройденный шаг где угодно остаются собранными; `wip` (недорешённая сетка) — только устройство.
- Плитка — вкладка «Чтение» `PracticePage.jsx`; Луна — `src/lib/assistant/destinations.js`.
- Оракул: ядра `XWCore`/`WSCore`/`LXClue` чистые (прототип сам гоняет их в Node) — снимок раскладок и
  выбора подсказок прототипа на урезанной фикстуре, красный `engine.test.js` = чинить порт.
- До выката бэкенда: `scripts/wordhunt/make-bundle.js <прототип> <out.json>` собирает бандл ровно по
  контракту (медиа — data-URI) — для e2e (`page.route('**/mobile/word-hunt**')`) и локального просмотра.
- Абзац раздела в `CLAUDE.md`.

backend → web-admin → сайт. Заливку на дев делает владелец.
