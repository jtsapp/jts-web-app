# JTS Классрум — состояния и учительская сторона. Design MD

Дата: 2026-08-05
Дополнение к **«JTS Классрум — доска урока. Design MD»** (макет Figma «Классрум — урок»).
Тот документ описывает студенческий экран 1440×900 в идеальном состоянии. Здесь — всё
остальное: состояния этого экрана и вся учительская сторона.

Читать вместе. Базовый документ дальше — **«спека»**. Ссылки вида «спека §5.1» — на его разделы.

---

## 0. Железные правила

Наследуются из спеки без изменений: одна светлая тема, никаких градиентов, никаких обводок и
рамок (разделение — фоном и отступами), скругления строго по шкале, две гарнитуры.

Добавляется три:

6. **Ни одного элемента, который выглядит рабочим и не работает.** Если функции нет — её нет
   в макете. Заглушка допустима только в явном виде: «Скоро» с объяснением, а не имитация.
7. **Каждая неудача видима.** У любого действия, которое ходит в сеть, есть состояние
   «не получилось» с причиной и способом повторить.
8. **Каждый режим виден и выключаем.** Если система вошла в состояние, где действия
   пользователя означают не то же, что обычно (трансляция, follow-me, блокировка доски) —
   на экране есть индикатор и явный выход из режима.

## 1. Правки к §1.1 спеки — доступность

Палитра остаётся. Меняются только пары «текст на заливке» — там, где текущие значения
не проходят WCAG 2.1 AA. Все числа посчитаны, не на глаз.

### 1.1 Правило on-color

Цвет текста на заливке выбирается по яркости заливки, а не по вкусу:

| Заливка | Текст | Контраст | Было |
|---|---|---|---|
| `#9047ff`, `#7a2fe6` | `#ffffff` | 4.63 | без изменений |
| `#1acf1a` | **`#181818`** | 8.44 | белый — 2.10 ❌ |
| `#ff474a` | **`#181818`** | 5.29 | белый — 3.36 ❌ |
| `#ff7300` | **`#181818`** | 6.51 | белый — 2.73 ❌ |
| `#00cbff` | **`#181818`** | 9.29 | белый — 1.91 ❌ |
| `#00ea00` | **`#181818`** | 10.80 | — |

Практически это меняет три места спеки: пилюли ответов ok/no (§4.3), свой пузырь в чате
(§5.3) и букву «У» на бегунке ученика (§3).

### 1.2 Новые токены-чернила

Яркие акцентные цвета работают как заливка, но не как текст. Для текста вводятся тёмные пары:

| Роль | HEX | Контраст |
|---|---|---|
| `ok-ink` — текст «верно» (поле-пропуск, подписи) | `#0d7d0d` | 5.31 на белом, 5.00 на `#e3ffeb` |
| `no-ink` — текст «неверно» | `#c92a2d` | 5.45 на белом, 4.69 на `#ffe9e9` |
| `error-surface` — фон ошибочного поля-пропуска | `#ffe9e9` | пара к `#e3ffeb` |
| `muted-ink` — приглушённый текст мельче 18px | `#706e6e` | 5.07 на белом, 4.77 на `#f8f8f8` |
| `track-idle` — неактивная точка/линия трека | `#8f8e8e` | 3.27 (норма для графики — 3:1) |

`#898787` из спеки остаётся, но только для текста от 18px или для чисто декоративных подписей.
`#c4c3c3` выводится из обращения: 1.76 — точка состояния на нём не читается.

### 1.3 Фокус с клавиатуры

Спека фокус не описывает. Единый стиль на весь продукт:

- Кольцо: `outline: 2px solid #9047ff`, `outline-offset: 2px`, скругление наследуется от элемента.
- На фиолетовой заливке кольцо белое: `outline: 2px solid #ffffff`, `outline-offset: 2px`.
- Показывается только по `:focus-visible` (клавиатура), не по клику мышью.
- Ни один интерактивный элемент не имеет `outline: none` без замены.

Порядок обхода на студенческом экране: хедер (выйти) → маршрут (шаги) → лента шагов
(задания сверху вниз) → правая колонка (звонок → топики → чат → поле ввода → отправить).

## 3. Состояния студенческого экрана

### 3.1 Загрузка

Скелет по месту будущего контента, никаких спиннеров по центру пустого экрана.

- Хедер собран сразу: логотип и «Выйти из урока» настоящие; бейдж уровня, название,
  шкала прогресса и таймер — плейсхолдеры `#eeecf3` своих размеров.
- Маршрут: карточка `329×486` на месте, внутри 9 строк-плейсхолдеров `#eeecf3` высотой 14,
  ширина чередуется 60%/80%/70%, `r-inner` (10).
- Центр: две карточки шага-плейсхолдера высотой 220 и 180, `r-step` (32), фон `#ffffff`,
  внутри 3 полосы `#eeecf3`.
- Правая колонка: три карточки своих размеров (309 / 225 / 322), внутри плейсхолдеры.
- Пульсация: `opacity` 1 → 0.55 → 1, 1.4s, `ease-in-out`, бесконечно. При
  `prefers-reduced-motion: reduce` — без анимации, статичная заливка `#eeecf3`.
- Скелет живёт максимум 10 с; дальше — состояние 3.5.

### 3.2 Урок ещё не начался

Ученик открыл класс до старта. Экран собран полностью, но контент шагов закрыт.

- Системный баннер (нейтральный) над лентой: иконка часов, **«Урок начнётся, когда преподаватель
  его откроет»**, справа — время начала по расписанию, `muted-ink`.
- Маршрут: все точки `track-idle`, заполнения нет, бегунков нет.
- Центр: одна карточка `r-step` (32), паддинг `40/22`, по центру — название урока
  PT Root UI Bold 21 и строка «Начало в 14:00 · 50 минут» PT Root UI Regular 15 `#504b4b`.
- Правая колонка: звонок в состоянии B (CTA «Позвонить учителю», спека §5.1), но кнопка
  неактивна: фон `#e8e3f3`, текст `muted-ink`, подпись под ней «Звонок откроется в начале урока».
- Чат активен — написать преподавателю можно до начала.

### 3.3 Пауза

Преподаватель поставил урок на паузу на N минут.

- Системный баннер (внимание): **«Перерыв 5 минут»** + обратный отсчёт `04:37` Manrope Bold 14.5
  `#181818`, справа — «Вернёмся в 14:23».
- Таймер урока в хедере останавливается и приглушается до `muted-ink`.
- Лента шагов остаётся видимой и прокручиваемой; поля ввода и варианты ответов — disabled
  (состояние 3.11), чтобы ответы не терялись в паузе.
- Бегунки замирают на своих позициях.

### 3.4 Урок завершён

- Системный баннер (нейтральный): **«Урок завершён»** + длительность «52 минуты».
- Лента остаётся доступной только для чтения: ответы видны, состояния ok/no сохранены,
  ввод и кнопки «Проверить» — disabled.
- Правая колонка: звонок скрывается целиком, на его месте карточка итога `328×…`, `r-card` (24),
  паддинг 16: «Выполнено 7 из 9 шагов» + шкала как в хедере, во всю ширину.
- Чат остаётся рабочим.
- «Выйти из урока» меняет подпись на **«Закрыть»** — выходить уже не из чего.

### 3.5 Ошибка загрузки урока

Единственное состояние, где экран не собирается.

- По центру области контента карточка `440×…`, `#ffffff`, `r-card` (24), паддинг `32/28`,
  выравнивание по центру:
  - Заголовок PT Root UI Bold 21 `#181818`: **«Не удалось открыть урок»**.
  - Текст PT Root UI Regular 15 `#504b4b`: причина по коду — «Нет соединения с сервером» /
    «Урок не найден» / «У вас нет доступа к этому уроку». Без кодов ошибок в интерфейсе.
  - Кнопка **«Попробовать снова»**: пилюля `#9047ff`, `r-pill`, паддинг `11/22`,
    Manrope Bold 14.5 `#ffffff`.
  - Ниже текст-кнопка «Вернуться к расписанию», Manrope Bold 14 `#7a2fe6`.
- Хедер остаётся: логотип и выход работают всегда.

### 3.6 Обрыв связи

Отдельно от 3.5: урок открыт, но живой канал отвалился.

- Системный баннер (внимание) под хедером, липнет к нему: иконка, **«Связь потеряна.
  Восстанавливаем…»**. Появляется через 3 с после разрыва — короткие обрывы не показываем.
- Пока баннер висит: чат в режиме «только чтение», поле ввода disabled с подписью
  «Отправим, когда связь вернётся»; бегунки других участников гаснут до 40% прозрачности;
  собственные ответы сохраняются локально.
- При восстановлении баннер меняется на нейтральный **«Связь восстановлена»** и уходит через 2 с.
- Если за 30 с не восстановилось — в баннере появляется действие «Обновить страницу».

### 3.7 Пустые данные

| Что пусто | Что показываем |
|---|---|
| Нет шагов | Карточка по образцу 3.5 с текстом «В этом уроке пока нет материалов. Преподаватель добавит их к началу занятия», без кнопки повтора |
| Нет топиков | Карточка топиков скрывается целиком (не показываем пустую рамку) |
| Нет чата (нет сообщений) | Карточка на месте, вместо списка — «Сообщений пока нет — напишите преподавателю», PT Root UI Regular 14 `muted-ink`, по центру области |
| Нет ссылки на звонок | Звонок в состоянии B, кнопка неактивна, подпись «Преподаватель ещё не добавил ссылку» |

### 3.8 Follow-me: преподаватель ведёт класс

Сейчас ученика перебрасывает на другой шаг молча. Так нельзя — это единственное место,
где интерфейс двигается сам.

- В момент перехода: системный баннер (нейтральный) с иконкой указателя,
  **«Преподаватель открыл: 04 Выбор формы»**, действие справа — **«Смотреть самому»**.
- Пока режим активен, у карточки текущего шага слева появляется полоса-маркер шириной 3,
  цвет `#9047ff`, `r 2`, во всю высоту карточки — «этот шаг открыл преподаватель».
- Прокрутка к шагу — плавная, 300 мс, `ease-out`. При `prefers-reduced-motion: reduce` —
  мгновенный переход без анимации.
- «Смотреть самому» выключает режим: баннер уходит, маркер снимается, дальше ученик листает
  сам. Следующий переход преподавателя снова включит режим (и снова покажет баннер).
- Бегунок «Т» в маршруте синхронно переезжает на этот шаг — это и есть визуальное объяснение,
  почему экран сдвинулся.

### 3.9 Преподаватель видит работу ученика

Каждый клик и ввод ученика уходят преподавателю. Об этом нельзя молчать.

- В шапке карточки маршрута, справа от «9 шагов», — пилюля-индикатор: `#f4f1fb`, `r-pill`,
  паддинг `4/10`, точка `6×6` `#00ea00` + текст «Преподаватель на связи» PT Root UI Medium 12 `#504b4b`.
- Когда преподаватель офлайн: точка `#8f8e8e`, текст «Преподаватель не в классе».
- Тултип по наведению и фокусу: «Преподаватель видит ваши ответы во время урока».
- Никаких скрытых состояний: если зеркалирование выключено (урок не идёт) — индикатора нет.

### 3.10 Чат: жизненный цикл сообщения

Сейчас при сбое сообщение исчезает без следа. Три состояния пузыря:

| Состояние | Вид |
|---|---|
| **Отправляется** | Пузырь `#ff7300` с текстом `#181818`, прозрачность 55%, справа от пузыря — точка `#8f8e8e` `4×4` |
| **Отправлено** | Полный пузырь `#ff7300`, текст `#181818` |
| **Не отправлено** | Пузырь `#ffe9e9`, текст `no-ink`, под ним строка: «Не отправлено» + текст-кнопка **«Повторить»** Manrope Bold 12.5 `no-ink` |

- Черновик не очищается до подтверждения отправки. При провале текст остаётся в пузыре
  и восстанавливается в поле по клику «Повторить».
- Время у сообщения: PT Root UI Regular 11 `muted-ink`, внутри пузыря справа снизу.
  Показывается у первого сообщения и дальше при разрыве больше 5 минут.
- Автопрокрутка вниз — только если список уже был внизу. Иначе — пилюля «Новое сообщение»
  над полем ввода: `#9047ff`, `r-pill`, паддинг `6/14`, Manrope Bold 12.5 `#ffffff`.

### 3.11 Ответы: проверено и повтор

- После проверки варианты и поля переходят в disabled: прозрачность 100% (состояние ok/no
  должно читаться), `cursor: default`, из порядка табуляции убираются.
- Под проверенным заданием — строка результата: иконка + «Верно» (`ok-ink`) или
  «Неверно. Правильно: **does**» (`no-ink`), PT Root UI Medium 14.
- Справа от строки результата — текст-кнопка **«Ещё раз»** Manrope Bold 14 `#7a2fe6`:
  сбрасывает ответы этого задания в none и снимает disabled.
- «Проверить» без единого ответа — кнопка неактивна: `#e8e3f3`, текст `muted-ink`.

### 3.12 Другое количество данных

Спека рисует 9 шагов и 5 топиков. Реальные значения плавают.

- Маршрут: при 12+ шагах карточка держит высоту `486` и скроллится внутри; трек и бегунки
  скроллятся вместе с ним; активный шаг подскроллен в видимую область автоматически.
- Маршрут: при 1–3 шагах карточка сжимается по контенту, минимальная высота 180.
- Шкала прогресса в хедере: сегменты `30×5` при 9 шагах; при другом количестве общая ширина
  фиксирована **294** (9×30 + 8×3), ширина сегмента = `(294 − 3×(N−1)) / N`, минимум 8;
  при N > 25 шкала заменяется на текст «Шаг 14 из 30» Manrope Bold 12.5.
- Топики: карточка растёт до 6 строк, дальше — внутренний скролл, высота фиксируется на 225.
- Название шага и топика: одна строка, обрезка многоточием, полное значение в `title`.
- Название урока в хедере: максимум 320px, дальше многоточие.

### 3.13 Выход из урока

`Выйти из урока` во время идущего занятия — деструктивное действие: ответы текущего шага
не сохранены.

Модальное окно: оверлей `rgba(24,24,24,0.45)`, карточка `420×…`, `#ffffff`, `r-card` (24),
паддинг `28/24`, gap 16.

- Заголовок PT Root UI Bold 21: **«Выйти из урока?»**
- Текст PT Root UI Regular 15 `#504b4b`: «Урок продолжается. Вернуться можно из расписания —
  ответы сохранятся.»
- Кнопки в ряд, gap 10, выравнивание вправо:
  - **«Остаться»** — пилюля `#f5eeff`, `r-pill`, паддинг `11/22`, Manrope Bold 14.5 `#7a2fe6`.
  - **«Выйти»** — пилюля `#9047ff`, `r-pill`, паддинг `11/22`, Manrope Bold 14.5 `#ffffff`.
- Фокус при открытии — на «Остаться». `Esc` = «Остаться».
- После завершения урока (3.4) окно не показывается — выход сразу.

### 3.14 Адаптив

Спека фиксирует 1440. Ниже — поведение на остальных ширинах. Правило: **маршрут и бегунки
не исчезают никогда** — это то, чем ученик понимает, где он и где класс.

| Ширина | Раскладка |
|---|---|
| ≥ 1280 | Три колонки 329 / 678 / 328, гаттер 20, поля 32 — как в спеке |
| 1024–1279 | Три колонки, левая 264, правая 300, центр — остаток; гаттер 16, поля 24 |
| 768–1023 | Две колонки: маршрут 264 слева, центр — остаток. Правая колонка уезжает вниз под ленту одной строкой из трёх карточек: звонок / топики / чат |
| < 768 | Одна колонка. Маршрут сворачивается в горизонтальную ленту под хедером: высота 56, липкая, точки и бегунки в ряд, активный шаг подскроллен в центр. Звонок, топики и чат — вкладками над лентой шагов, высота вкладки 44 |
| < 768, чат | Чат разворачивается на всю высоту области контента; поле ввода липнет к низу |

Хедер на < 768: логотип и бейдж уровня остаются, название урока скрывается, шкала прогресса
заменяется текстом «4 / 9», таймер и «Выйти» остаются.

## 4. Учительская сторона

Спека студенческого экрана исключает учителя явно. Здесь он описан целиком.

### 4.1 Чем учительский экран отличается

Один принцип: **у учителя тот же урок, но он видит класс, а не только себя.** Отсюда три
отличия, всё остальное наследуется.

1. Никакой геймификации. У учителя нет уровня, роли, монет и стрика — это ученические сущности.
2. Правая колонка — не только звонок и чат, а прежде всего **класс**: кто пришёл, кто где идёт,
   чью работу я сейчас смотрю.
3. Есть управление: жизненный цикл урока, трансляция, ограничения доски.

### 4.2 Оболочка роли

Учитель не видит ученической навигации (Обучение, Практика, Тьютор, IELTS, Словарь).

**Вне урока** (расписание, каталог): узкий сайдбар шириной **88**, фон `#ffffff`, три пункта

### 4.8 Режим «Показать всем»

Сейчас режим включается и не подаёт признаков жизни. Правило 8 из §0 закрывается так:

- Нажатие «Показать всем» переводит панель трансляции (§4.5) в активный вид:
  вся панель заливается `#9047ff`, текст слева становится белым:
  **«Веду класс — ученики видят этот раздел»**, кнопка справа меняется на
  **«Остановить»** — пилюля `#ffffff`, `r-pill`, паддинг `9/18`, Manrope Bold 14 `#7a2fe6`.
- Пока режим активен, у карточки материала слева полоса-маркер 3, `#9047ff`, `r 2` — тот же
  язык, что у ученика в §3.8.
- Режим выключается кнопкой «Остановить», переходом на другой раздел или завершением урока.
  При переходе на другой раздел — системный баннер (нейтральный) на 3 с:
  «Трансляция остановлена».
- Пока режим активен, переключение просматриваемого ученика в панели «Класс» не выключает
  трансляцию: учитель ведёт по разделу, а смотреть может чью угодно работу.

## 5. Что требует бэкенда

Честный список: без этого часть спеки не собирается. Проверено по `src/api.js`.

**Уже есть, интерфейс просто не пользуется:**

- Просмотр работы конкретного ученика — `lessonMaterialRenderUrl(..., { studentId })`
  принимает `studentId`, участники приходят в `lesson.participants`. Панель «Класс» (§4.6)
  собирается без единой правки на бэкенде.
- Перерыв на произвольное число минут — `pauseLiveLesson(token, id, minutes)`.
- Ссылка на всю серию занятий — `setLessonMeetingUrl(..., wholeSeries)`.

**Нужно добавить:**

- **Позиция участника в маршруте.** Бегунки (§4.4) и «ШАГ 04» в панели класса требуют
  события «участник открыл раздел N». Сейчас presence отдаёт только `onlineUserIds` —
  ни позиции, ни имени. До появления события бегунки учеников не рисуем совсем
  (не заменяем их догадкой), а показываем только бегунок «Я» и присутствие точкой.
- **Имя в presence.** Сейчас имена резолвятся из загруженного урока; для гостя, которого нет
  в `participants`, будет `#123`.
- **Прогресс по шагам для сводки** «Выполнено 7 из 9» (§3.4) — сейчас считается только
  клиентски и только для своей сессии.
