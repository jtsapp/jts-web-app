# Prepositions World — раздел «Практики»: предлоги, материал из админки

Дата: 22.10.2026. Источник — прототип методиста «Prepositions World» (standalone html, 23 МБ,
прислан в чате 22.10.2026). Второй присланный прототип — «Cartoon World» — отдельный раздел,
своя спека.

## Что это

Курс английских предлогов в две стадии.

- **Learn** — 8 категорий (place, time, movement, manner, cause, relations, patterns, advanced),
  31 урок. Урок — несколько экранов из блоков (правило, сравнение, таблица, список, заметка,
  схема, сцена), в конце — «Common mistakes» и «Remember». Английский показан всегда, перевод
  kk/ru — строкой под ним.
- **Practice** — наборы вопросов с картинкой-сценой: урок (12–14 вопросов), обзор категории,
  финальный обзор (~78). Шесть типов: gap, fix, compare, dialogue, scene (генерируется из
  геометрии сцены), passage. Ответ — один клик, после него фидбек: верный ответ, перевод,
  «почему» на трёх языках, запись предложения. Итог — звёзды (3★ ≥ 90 %, 2★ ≥ 70 %, 1★ > 0).

Набор урока открывается после чтения урока, обзор категории — после всех её уроков, финал —
после всех 31.

## Решения владельца (22.10.2026)

- «Prepositions World» и «Cartoon World» — **два отдельных раздела**; этот первый.
- Материал **транслируется с бэкенда**, как караоке, комиксы и Just Listen It: в бандле сайта
  его нет.
- Методист заводит материал **заливкой прототипа целиком** (как Just Listen It и «Словарь»):
  правит html и загружает его в web-admin. Поштучных форм и пакета zip нет.
- Движок переносится на сайт **почти дословно** (как «Числа» и SpeakSpin), а не переписывается
  на React.

## Прототип: что в нём

Данные лежат пятью блоками `<script type="application/json" id="…">` и одним JS-литералом:

| Блок | Объём | Что |
|---|---|---|
| `course` | 0.78 МБ | `{cats[8]}`: категории, уроки, экраны, блоки, ошибки, вопросы (`practice`, `integrated`), источники |
| `pics` | 182 КБ | 448 сцен вопросов, ключ `<catId>/<lessonId>/<i>` или `<catId>/int/<i>` — индекс вопроса |
| `pcat` | 7.5 КБ | 188 пропов: имя, класс размера |
| `assets` | 13.6 МБ | `{img: {key: dataURI webp}, size: {key: [w,h]}, slots}` — 266 картинок |
| `aud` | 8.3 МБ | `{fnv8hex[_n]: dataURI mp3}` — 502 записи, ключ — FNV-1a от английского предложения |
| `const PDEF = {…}` | 11 КБ | толкования 19 пространственных предлогов (en/kk/ru) для «почему» в scene-вопросах |

Остальное — движок (~97 КБ JS, ~34 КБ CSS): геометрия сцен, раскладка картинок, виджеты
(часы, календарь, маршрут), 23 схемы `DG`, библиотека сцен `SC`, роутер, сессии. Константы
движка (`PH`, `SYN`, `SC`, `DG`, `MASC`, `ART`, `RH` …) — полу-контент, но живут в коде: их
правка требует PR сайта (см. «Предупреждение о движке»).

## Часть 1. Backend — модуль `prepositions`

Образец — модуль `listen` (Just Listen It, V392) и общий `modules/practice` (медиа по хэшу).

### Загрузка

`POST /admin/prepositions/upload` (multipart `file`, только ADMIN).

1. **Разбор** `PrepositionsHtmlParser`:
   - блоки `course|pics|pcat|assets|aud` — по тегу `<script type="application/json" id="X">`
     до ближайшего `</script>`, затем Jackson;
   - `PDEF` — `shared/util/JsLiterals` (`const PDEF=` → `jsToJson`);
   - **хэш движка** — sha256 текста всех `<script>` без `type="application/json"`, из которого
     вырезан литерал `PDEF`, переводы строк приведены к `\n`.
2. **Проверка** — ошибка отклоняет всю загрузку с понятным текстом, ничего не пишем:
   - нет любого из пяти блоков или `PDEF`, блок — не JSON;
   - у категории нет `id`/`lessons`, у урока — `id`/`screens`/`practice`, id уроков повторяются;
   - вопрос неизвестного типа; у gap/fix/dialogue `ans` нет среди `opts`; у compare `ans` — не
     индекс `opts`; у passage у гэпа `ans` нет среди его `opts`;
   - у не-scene вопроса нет сцены в `pics` (движок прототипа на этом падает);
   - сцена или проп ссылается на картинку, которой нет в `assets.img`;
   - картинка не webp, запись не mp3 (по сигнатуре байтов, не по data-URI);
   - картинка или запись больше 20 МБ (`PracticeMediaService.MAX_BYTES`).

   Предупреждения (загрузка проходит, список — в ответе `warnings`):
   - у вопроса нет записи в `aud` (кнопки «Listen again» у него не будет);
   - картинки и записи, на которые ничто не ссылается (их всё равно заливаем: часть ссылок
     строит код движка);
   - **хэш движка не совпал** с `prepositions.engine-sha` (настройка бэкенда, ставится при
     переносе движка на сайт): «Движок в файле отличается от перенесённого на сайт: правки
     данных применятся, правки движка (схемы, сцены, логика) — нет, нужен PR сайта».
3. **Медиа** — через `PracticeMediaStorage`, раздел `prepositions`:
   `practice/prepositions/<sha24>.webp|mp3`, `Cache-Control: public, max-age=31536000, immutable`,
   публичный бакет — сайт берёт файл прямо оттуда (`<image href>`, `<audio src>` CORS не
   нужен). Что уже лежит — один `list` раздела, грузятся только новые.
   Доработки общего кода: `SECTIONS += "prepositions"`, имя `^[a-f0-9]{24}\.(mp3|webp)$`,
   `sniff` узнаёт WebP (`RIFF….WEBP`), `CONTENT_TYPE` webp → `image/webp`,
   `PracticeMediaStorage.delete(section, name)`. Поведение Аудирования не меняется.
4. **Бандл** `bundle.json` — то, что получит сайт (~1 МБ, gzip бэкенда включён для JSON):

   ```json
   {
     "release": 3,
     "uploadedAt": "2026-10-22T12:00:00Z",
     "course": { "cats": [ … как в прототипе … ] },
     "pics": { … как в прототипе … },
     "pcat": { … как в прототипе … },
     "pdef": { … как в прототипе … },
     "assets": {
       "img": { "bg_street": "https://files-dev…/practice/prepositions/<sha24>.webp", … },
       "size": { "bg_street": [1280, 720], … },
       "slots": { … как в прототипе … }
     },
     "aud": { "6f8608e4": "https://files-dev…/practice/prepositions/<sha24>.mp3", … }
   }
   ```

   Форма та же, что у прототипа, — только data-URI заменены ссылками. Так движок меняется
   минимально, а оракул прототипа годится как есть.
5. **Порядок записи:** медиа → `prepositions/current/bundle.json` (`PrepositionsStorageService`,
   как `ListenStorageService`, с режимом `prepositions.storage=local` для разработки) → строка
   релиза → сброс кэша → удаление медиа раздела, на которые новый бандл не ссылается.
   Бандл не ссылается на недолитый файл; удаление — последним.
6. **Таблица** `prepositions_releases` (миграция — следующий свободный номер, сейчас **V393**;
   сверить с develop перед мержем): `id, file_name, lessons_count, questions_count,
   images_count, audio_count, engine_sha, uploaded_by → users ON DELETE SET NULL, created_at`
   + индекс по `created_at DESC`. Только мета.

Ответ загрузки: `{release, lessons, questions, images, audio, uploadedMedia, reusedMedia,
removedMedia, engineMatches, warnings: []}`.

### Чтение

- `GET /admin/prepositions` → текущий релиз + последние 20 загрузок.
- `GET /mobile/prepositions` → `bundle.json` телом (бакет без CORS); кэш в памяти до следующей
  загрузки. До первой загрузки — `404` («Prepositions World ещё не загружен»). Нужен Bearer, как у
  `/mobile/listen`.

### Тесты backend

На Mockito, без WebMvc-срезов (они красные из-за `IeltsAccessInterceptor`). Фикстура —
урезанная копия прототипа (см. «Фикстура»), лежит в `src/test/resources/prepositions/`.

- парсер: пять блоков, `PDEF`, хэш движка не зависит от `PDEF` и переводов строк, каждая
  ошибка проверки, каждое предупреждение;
- загрузка: медиа по хэшу, повтор не перезаливает, в бандле ссылки вместо base64, порядок
  записи, удаление лишнего медиа последним, строка релиза, сброс кэша;
- `PracticeMediaNames`: webp, прежнее поведение mp3;
- чтение: кэш, 404 до первой загрузки.

### Риск

Файл — 23 МБ одним POST. Караоке на 21 МБ проходило nginx dev-server; перед заливкой на дев
проверить `client_max_body_size` перед бэкендом (multipart самого приложения — 512 МБ).

## Часть 3. Сайт

### Экран и движок

- Экран `?screen=prepositions` — `src/screens/PrepositionsPage.jsx`, ветка в `App.jsx`.
- Движок — `src/practice/prepositions/engine.js`: скрипт прототипа почти дословно,
  `mountPrepositions(root, cfg) → destroy`, монтируется в Shadow DOM (классы прототипа `.hero`,
  `.btn`, `.top`, `.card` совпадают с глобальными). CSS прототипа — `styles.js`, гарнитуры —
  `inherit` от хоста тени (Manrope, на телефоне PT Root UI, в kk — Inter), как у «Чисел»;
  Golos Text прототипа не переносится.
- `cfg`: `{bundle, lang, progress, onProgress, onAnswer, playUrl, speak, onExit}`.

Отступления от прототипа (всё остальное — как есть):

| Прототип | Порт | Почему |
|---|---|---|
| Данные из `<script id=…>` в документе | из `cfg.bundle` | материал с бэкенда |
| Все 266 картинок `<symbol><image href=data:…>` в DOM, ссылки `<use href="#a-key">` | одна функция рисует `<image href=URL>` на месте каждого `<use>`; баннеры категорий — `background-image: url(URL)` | 13 МБ base64 в DOM на старте; ссылки внутри тени — лишний риск в Safari; браузер грузит только видимое |
| Роутер на `location.hash`, ссылки `<a href="#/…">` | внутреннее состояние движка, клики по `a[href^="#/"]` в корне тени перехватываются | адрес приложения не трогаем (App — state-машина `screen`) |
| `localStorage` `jts_prepositions_v4` | `cfg.progress` / `cfg.onProgress` | прогресс синкается с аккаунтом |
| `speechSynthesis` в уроках | `cfg.speak` → `/api/tts` (Soniox), по `onFail` — голос устройства | правило проекта: озвучка без записи — Soniox |
| `new Audio(dataURI)` в практике | `cfg.playUrl` (`src/lib/speech.js`) | один `<audio>` на приложение — иначе молчит iPhone |
| `jtsPrepLang` | `cfg.lang` + `jts_prepositions_lang` на устройстве | по умолчанию — язык интерфейса |
| Шапка с логотипом JTS | без логотипа, «назад» с главной раздела → `cfg.onExit` | шапка приложения уже есть |

Баги прототипа, которые чиним в порте:

1. «Previous» с первого экрана урока ведёт на итог предыдущего урока — ведёт к списку уроков.
2. На главной раздела и в списке практики нет переключателя языка — добавляем.
3. Сборка сессии падает целиком, если у вопроса нет сцены или scene-факт не подтвердился
   геометрией (`throw`) — такой вопрос пропускается, остальные идут.
4. Общие вопросы категории (`integrated`) приписаны последнему уроку категории, и «Review these
   lessons» советует не тот урок — у них урока нет, в совет они не попадают.
5. Смена языка в уже отвеченном вопросе не обновляет перевод задания — перерисовываем вопрос
   целиком с сохранением ответа.

Ошибки контента в коде НЕ чиним — их правит методист в html, список — в отчёте PR: «Мия» вместо
Aizere в переводах примеров, «Spark is between the coral and the coral», «The hollow tree is
outside the tent», дубли вопросов (`f_over`, `ic_into`), alt `time/time-at-on-in/0` не про
картинку.

### Данные

- `getPrepositions(token)` в `src/api.js` → `GET /mobile/prepositions`. Кэш — только в памяти
  вкладки: бандл ~1 МБ, в `localStorage` ему не место (квота уже съедала прогресс Практики).
- Хук `src/screens/prepositions/usePrepositionsData.js`, статусы как у Just Listen It:

### Прогресс

- Модуль синка `prepositions` (`src/lib/practiceContract.js`, replace), состояние —
  `{done: {<lessonId>: 1}, score: {"L:<lessonId>" | "C:<catId>" | "F": {best, stars}}}`, как в

- `src/practice/prepositions/progress.js` — `merge(a, b)`: прочитанное объединяется, у
  результата берётся лучший `best` и больший `stars`; сводится со снимком сервера, как у «Чисел».

- Домашки и квоты нет: area `prepositions` бэкенду неизвестна.
- `jts_prepositions_lang` чистится при выходе вместе с прочей Практикой.

## Фикстура

`scripts/make-prepositions-fixture.js --html <прототип>` режет настоящий прототип в маленький
html того же формата: категория `place` с двумя уроками (вопросы всех типов, кроме passage) +
её `integrated` (есть passage), только нужные им сцены, картинки и записи (картинки
пережимаются в 8×8). Получается валидный прототип на десятки КБ — один и тот же файл
используют бэкенд (тест разбора), сайт (бандл для e2e, вход оракула) и ручная проверка
админки. Сам прототип (23 МБ) в git не кладётся.

## Выкатка

1. Worktree от свежего `origin/develop` во всех трёх репо (локальные копии отстают).
2. Три PR в develop по порядку: backend → web-admin → сайт. Сайт без загруженного раздела
   показывает «Раздел готовится» — его мерж ничего не ломает.
3. Номер миграции сверить с develop перед мержем.
4. Перед заливкой — лимит тела nginx перед дев-бэкендом.
5. Заливает владелец в дев-админке. Проверка на деве: `data-release` на экране, картинки и
   записи с files-dev с `immutable`, путь ученика, прогресс на втором устройстве (второй
   браузер), повторная заливка того же файла — 0 новых медиа.
6. В прод — обычным develop → main. Бэкенд уезжает только со всем develop; сайт можно выкатить
   отдельно — без ручки на проде он показывает «Раздел готовится».
7. Раздел — абзацем в CLAUDE.md; `prepositions.engine-sha` — в `application.yml` бэкенда
   значением хэша перенесённого движка.

## Не делаем

- Поштучное редактирование уроков и вопросов в админке, скрытие отдельных вопросов.
- Перенос констант движка (`SC`, `DG`, `PH`, `SYN` …) в данные.
- Proxy-отдачу медиа через бэкенд, статический фолбэк в `public/`.
- Premium/замки по тарифу, домашние задания, XP.
