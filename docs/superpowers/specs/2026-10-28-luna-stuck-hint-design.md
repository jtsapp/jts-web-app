# Луна: «Застряли? Подсказать?» — дизайн

Дата: 28.10.2026. Решения владельца — в разговоре 28.10 (ответы на три вопроса, «Да, делай»).

## Зачем

Луна — «преподаватель», но говорит, только когда её позвали. Ученик, который ошибается снова и
снова или замер над заданием, остаётся один, пока сам не догадается нажать на кнопку. Нужен
мягкий сигнал от Луны в нужный момент — не мешающий (руководство 16.10: «не мешать при работе с
платформой»).

## Что видит ученик

У кнопки Луны выезжает облачко «Подсказать?» (kk «Көмектесейін бе?», en «Need a hint?»). Его
можно нажать; нажатие на саму кнопку Луны, пока облачко на экране, делает то же. По нажатию
открывается окно, и Луна сразу разбирает задание на экране — голосом, если звук не выключен
(нажатие — жест, iPhone звук пустит), иначе текстом.

Облачко уходит само через 12 с, по нажатию и когда ученик снова взялся за задание (клик, ввод,
клавиша внутри экрана).

## Когда облачко выходит

1. **Две неверные проверки подряд** на одном экране: между ними нет верной. Переход к следующему
   заданию счёт не сбрасывает — в уроках «Обучения» после ошибки сайт показывает ответ и ведёт
   дальше, перепроверки нет, и «две подряд на одном задании» там не бывает. Сбрасывают: верная
   проверка, уход с экрана, показанное облачко.
2. **90 с без действий на экране с заданием**: ни клика, ни клавиши, ни прокрутки, ни ввода; при
   этом на экране задание (`openingFocus(snapshot).task`), вкладка видна, не играет аудио/видео
   страницы и не звучит Луна (`isTtsActive`).

## Когда не выходит

- Тесты и зачёты: тест уровня курса (`LevelExam`), тесты юнитов курса (`exam` в
  `CourseStepPlayer`), зачёты воркбука (`lesson.test`). Их корень помечается
  `data-assistant-test`; экран, где такой узел есть, наблюдатель пропускает. Экраны, где Луны нет
  вовсе (`visibility.js`), — само собой.
- Окно Луны открыто, идёт звонок, Луна говорит, на экране тур (`.t-tour__pop`), облачко
  позывного или вводное облачко «Я Луна…».
- Чаще раза в 3 минуты; повторно на тот же экран — только после новой пары ошибок.
- Ученик дважды подряд дал облачку уйти, не нажав, — до конца визита (перезагрузки) оно не
  выходит: мешает.
- Ученик без входа (нет токена) — Луны нет.

## Как это устроено

**Сигнал — экран, а не разделы.** Окно Луны само смотрит на экран той же разметкой, по которой
Луна читает задания (`screenSnapshot.js`): варианты и поля с пометкой «(отмечено как неверное)»
или «(отмечено как верное)», эталон «[верный ответ по заданию: …]» (ставится только после
неверного ответа). Разделы не трогаем: всё, что размечено для Луны, подхватывается само.
Отвергнуто: события из каждого раздела (~15 правок, новый раздел забудет) и `recordSkill` (нет в
уроках «Обучения», считает только первую попытку).

**Что считается неверной проверкой.** После каждого действия ученика внутри экрана (клик, Enter)
окно через ~0.8 с и ещё раз через ~2 с снимает экран и выделяет «подпись неверного» — все
токены с «неверное» и эталон. Подпись непустая и не такая, как в прошлом снимке, — это новая
неверная проверка. Новая подпись верного без нового неверного — верная проверка (сброс). Та же
подпись (ученик нажал «Послушать») — ничего. Повторный неверный ввод меняет «ученик ввёл «…»» в
подписи — засчитывается.

**Модули.**
- `src/lib/assistant/stuck.js` — чистая логика: `verdictMarks(snapshotText)` → `{ wrong, right }`
  (подписи), `createStuckTracker({ wrongLimit: 2, idleMs: 90_000, cooldownMs: 180_000,
  ignoreLimit: 2 })` → `observe({ text, screen, now })` (после действия),
  `idle({ text, screen, now, lastActionAt })`, `shown()`, `taken()`, `ignored()`; возвращает
  причину `'errors' | 'idle' | null`. Под vitest.
- `src/lib/assistant/useStuckWatch.js` — хук в окне: слушатели действий (capture, с учётом Shadow
  DOM через `composedPath`), таймеры снимков, проверка «можно ли сейчас» (тест, тур, звук, окно,
  звонок), отдаёт `{ reason, dismiss, take }`.
- `src/lib/assistant/opening.js` — пометки `STUCK_ERRORS_MARK = '[ученик застрял: две ошибки
  подряд]'`, `STUCK_IDLE_MARK = '[ученик застрял: долго без действий]'`, `isStuckTurn`;
  `isOpeningTurn` их включает (служебный ход: ни «не по теме», ни отчёта о поломке).
- `prompt.js` `buildTurns` — указание рядом с пометкой (а не в RULES: правила экрана Haiku 5.5
  держит только так, замеры 15.10 и 21.10): «Ученик застрял на задании на экране (…). Разбери
  именно его: что не так или на что посмотреть. Не проверено или сайт даёт перепробовать — только
  подсказка, без ответа; верный ответ — только если сайт его показал. Без советов про другие
  разделы и без метки. Не больше 4 коротких предложений.» Профиль — без «Совета сайта».
- `chat/route.js` — на пометке «застрял» действий нет (как у позывного), заметку трекера не пишет,
  строка лога `[assistant] {"kind":"stuck","reason":"errors|idle"}` без текста — сколько раз
  облачко нажимали.
- `AssistantWidget.jsx` — облачко-кнопка `.asst__hint.asst__hint--stuck` рядом с кнопкой (та же
  раскладка, что у вводного облачка), нажатие → `unlockSpeech`, открыть окно,
  `send(mark, { voice: !muted, opening: true })`, запомнить экран (`greetedRef`), чтобы обычное
  открытие следом не повторило первую реплику.
- Пометка тестов: `data-assistant-test` на корне `LevelExam`, на плеере при `exam` в
  `CourseStepPlayer`, на `WorkbookAct` при `lesson.test`.

## Проверка

- vitest: `stuck.test.js` — подписи по снимкам (вариант, поле с вводом, эталон, «Послушать» без
  изменений, повторный ввод), счёт/сброс, простой, кулдаун, «дважды проигнорировал»;
  `prompt.test.js` — указание рядом с пометкой; роут — без действий и без заметки.
- e2e `tests/assistant-stuck.spec.js` (подмена модели): урок курса — две ошибки → облачко → окно,
  в чат ушла пометка «две ошибки подряд»; одна ошибка — облачка нет; тест юнита — облачка нет.
- Зонд Haiku 5.5 с параметрами роута (`buildSystemPrompt`/`buildTurns`): 4 сценария × 4 —
  урок после двух ошибок с эталоном, воркбук до окончательной проверки, простой на непроверенном
  задании, казахский интерфейс. Критерии: нет ответа там, где проверка не окончательна; нет
  метки; не больше 4 предложений; язык ответа верный.

## Не входит

Итог после урока, «Запомни слово», выделение текста — отдельные задачи. Настройка порогов из
админки — нет (константы в `stuck.js`).
