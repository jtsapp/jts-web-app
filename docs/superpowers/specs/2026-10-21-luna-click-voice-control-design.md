# Луна нажимает кнопки и слушается голоса — дизайн

21.10.2026, запрос владельца: «дать голосовому ассистенту больше прав, чтобы он мог нажимать на кнопки, и в общем
голосовое управление». До этого Луна (Айзере при казахском интерфейсе) по экрану не кликала — только открывала раздел
(`[[OPEN…]]`) и запускала тур (`[[TOUR…]]`), см. CLAUDE.md «Луна открывает разделы и водит турами».

## Решения владельца (21.10.2026)

1. **Что можно нажимать** — любую видимую кнопку экрана по просьбе ученика, кроме опасных: выход, удаление,
   оплата/покупка/подписка, «Сдать / Отправить / Завершить» (тест, домашка, работа), сброс, пароль. Вариант ответа на
   непроверенном задании — только если ученик сам его назвал; сама Луна ответ не выбирает.
2. **Голос** — «Луна, …» сразу команда: без приветствия, короткий сигнал «слушаю», нажатие и короткое подтверждение.
   Те же нажатия — из микрофона окна и в звонке.
3. **Окно** — на команду голосом окно не открывается: у кнопки Луны облачко «Слушаю… → Нажимаю «Далее»». Ответ без
   нажатия (объяснение) открывает окно с перепиской.
4. **Мозг** — модель + быстрые команды на устройстве: короткие команды распознаёт сам Vosk «уха» и нажимает без
   сервера; всё остальное — через `/api/assistant/chat`.

## 1. Номера кнопок в снимке экрана

`screenSnapshot.js` получает вариант `snapshotWithRefs(root)` → `{ text, refs }`: каждой нажимаемой кнопке (тот же
признак, что сейчас: `<button>`, `input[type=button|submit]`, роли из `PRESSABLE_ROLES`) — номер по порядку обхода,
сквозной для окон-порталов и экрана: `[кнопка #7 «Проверить»]`. `refs` — `Map<number, {el, label}>`. Неактивная
кнопка (`disabled`, `aria-disabled`) номер не получает — нажать её нельзя. Кнопка под запретом (раздел 3) тоже без
номера: модель не увидит, что её можно просить. Прежний `snapshotScreen(root)` остаётся и отдаёт `text`.

`screenStateKey` выбрасывает цифры — номера ключ «один раз на экран» не ломают.

## 2. Метка нажатия

Модель: `[[CLICK 7]]` — предложить (под ответом кнопка «Нажать «Проверить»»), `[[CLICK_NOW 7]]` — нажать сразу. Те же
правила, что у OPEN: `_NOW` — только по прямой просьбе («нажми», «дальше», «проверь», «включи») или согласию; ответ,
который кончается вопросом, — без `_NOW`. Одна метка на ответ.

Роут (`createActionFilter` в `actions.js`) разбирает метку, сверяет номер со снимком, пришедшим в запросе (строка
`[кнопка #7 «…»]`), и берёт подпись оттуда: действие `{ kind: 'click', target: '7', label: 'Проверить', now }`. Номера
нет в снимке — метка вырезается, действия нет. Хвост стрима: `[[ASST_ACTION click 7 now «Проверить»]]` (подпись — чтобы
окно сверило элемент и подписало кнопку предложения).

Окно выполняет нажатие (`lib/assistant/clicker.js`): элемент из `refs` последнего снимка ещё в документе, виден, не
неактивен и подпись та же — `el.click()`. Иначе ищет на экране кнопку с той же подписью; ровно одна — нажимает; нет —
строка «Кнопка «…» пропала с экрана», без нажатия. `CLICK_NOW` выполняется сразу по приходу метки, не дожидаясь голоса
(в отличие от OPEN): нажатие не уводит из окна, а «нажимаю…» голосом только задерживало бы. На телефоне открытое окно-
лист после нажатия закрывается — как после перехода.

## 3. Запреты и честность — в коде

`lib/assistant/clickPolicy.js` (чистый, общий для окна и роута):

- **Запрещённые подписи** (ru/kk/en, по словам, без учёта регистра): выйти / выход / шығу / log out, удалить / жою /
  delete, оплатить / купить / оформить / подписк / төлеу / сатып / pay / buy / subscribe, сдать / отправить /
  завершить / тапсыру / жіберу / submit / send / finish, сбросить / reset, пароль / password. Плюс атрибут
  `data-assistant-noclick` на самой кнопке или предке — для кнопок, которые словами не поймать.
- **Честность**: на экране с непроверенным заданием (`openingFocus(text).unchecked`) нажатие разрешено, только если
  ученик назвал эту кнопку сам: половина слов подписи есть в его реплике (с основами: «проверь» называет «Проверить»,
  «выбери like» — «like», но не «don't like») или он сказал команду этой кнопки («дальше» → «Далее», «включи» →
  «Послушать», `voiceCommands.js`). Список «служебных» подписей не годится: варианты ответа в английском задании
  бывают и «play», и «start», а в переводе — «продолжить». Иначе роут действие снимает.

Модель о запретах знает из RULES (чтобы не обещать «нажимаю «Выйти»»), но решает код: роут снимает запрещённое и
нечестное нажатие, окно перед нажатием проверяет запрет ещё раз (снимок мог устареть).

## 4. Голос «Луна, …»

**Быстрые команды (Vosk).** В грамматику позывного добавляются фразы «имя + команда» (`луна дальше`, `луна назад`…) и
сами команды — словами-ловушками. Список (`lib/assistant/voiceCommands.js`):

| команда | слова (ru) | какие кнопки |
|---|---|---|
| next | дальше, далее, следующий, продолжи | Далее, Дальше, Следующий, Продолжить, Next, Continue, Келесі |
| back | назад, вернись | Назад, Back, Артқа |
| check | проверь, проверить | Проверить, Check, Тексеру |
| replay | повтори, послушать, ещё раз | Послушать, Повторить, Ещё раз, Play, Replay, Тыңдау |
| stop | стоп, хватит, пауза | Пауза, Стоп, Pause, Stop (и Луна замолкает) |
| close | закрой | Закрыть, ×, Close, Жабу |

Казахские слова у Айзере сверены со словарём `vosk-model-small-kz-0.42` (Gr.fst, 21.10.2026): келесі, әрі/ары
қарай, артқа, кері, тексер, тексеру, қайтала, тыңда, тоқта, жап, жабу — есть; там же есть русские «дальше», «назад»,
«стоп», а «проверь» нет. В русской модели все слова таблицы есть, «ещё» — только через «ё» (сверка — после `norm`).

`matchCommand(text, persona)` — после имени ровно команда (1–2 слова, без `[unk]`) → id команды. Окно ищет на экране
кнопки команды (`findCommandButtons(refs, id)`): ровно одна → нажатие сразу, облачко «Нажимаю «Далее»», тихий
щелчок, без голоса и без запроса к серверу. Ноль или несколько → текст команды уходит модели обычным голосовым
вопросом.

**Фраза одним духом.** Vosk отдаёт итог после паузы — значит, к срабатыванию позывного ученик договорил. «Ухо» держит
кольцевой буфер последних 8 с звука и счёт поданных сэмплов; Vosk даёт время слов, поэтому от начала слова-имени до
конца звучит именно обращение. Если после имени в итоге есть слова (`[unk]` или ловушки, не команда) — этот кусок
уходит WAV 16 кГц в `/api/assistant/transcribe`, имя и «привет/сәлем» срезаются с начала текста, остаток — голосовой
вопрос модели. Ученик не обязан ждать после имени.

**Только имя.** «Луна» и пауза → сигнал «слушаю», запись вопроса (`useVoiceQuestion`) до 6 с без речи; заговорил —
вопрос модели; промолчал — прежнее приветствие (`WAKE_MARK`).

**Облачко вместо окна.** На голосовую команду окно не открывается; у кнопки Луны облачко состояния (`Слушаю… /
Думаю… / Нажимаю «…» / текст ответа`). Ответ пришёл с нажатием или переходом — облачко живёт 3 с после голоса и
уходит. Ответ без действия — окно открывается, переписка в нём; голос как обычно.

## 5. Звонок

Мозг звонка — в окне (`callBridge.js`), поэтому нажатие в звонке — та же метка и тот же `clicker`. Быстрая ветка — на
тексте реплики (`matchCommand` без имени: в звонке Луну звать не нужно): «дальше» в звонке → нажатие и короткая фраза
`luna.reply` «Нажимаю «Далее»» без модели. Агент не меняется, деплой агента не нужен.

## 6. Промпт

В RULES — блок «Нажать кнопку» (когда `CLICK` и когда `CLICK_NOW`, номер — только из снимка, запреты, честность,
ответ с нажатием — одно короткое предложение). Правка промпта — только по живому замеру Haiku 5.5 (зонд с
`buildSystemPrompt`/`buildTurns`, параметры роута, ≥ 20 сценариев: «нажми проверить», «дальше», «включи запись»,
«выбери like» до проверки, «выбери сама», «выйди из аккаунта», «где тут кнопка» — без нажатия, OPEN не ломается).

## 7. Проверка

- vitest: номера в снимке (неактивные и запрещённые — без номера, порталы сквозные), `clickPolicy` (запреты ru/kk/en,
  честность), `actions.js` (метка CLICK, номер не из снимка, хвост), `voiceCommands` (`matchCommand`, поиск кнопок),
  `clicker` (элемент пропал → поиск по подписи), кольцевой буфер «уха».
- e2e: подменное «ухо» `__jtsFakeWakeEar` → «луна дальше» → кнопка нажата без запроса к чату; «луна нажми начать» →
  чат с подменой модели → `CLICK_NOW` → нажата; запрещённая кнопка не нажимается.
- Живой зонд модели (раздел 6).

## Не входит

Ввод текста в поля под диктовку; цепочки действий («открой словарь и нажми…» — одно действие на ответ); кнопки бокового
меню (их покрывает OPEN). Известное ограничение: на iPhone звук, который запускает её нажатие без касания экрана, может
не заиграть — браузер требует жест.
