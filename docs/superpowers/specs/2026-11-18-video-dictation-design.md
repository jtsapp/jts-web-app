# Видеодиктант по мультикам — дизайн

Дата: 18.11.2026. Статус: дизайн согласован владельцем, ждёт плана.

## Зачем

Владелец хочет упражнение, как в приложениях-«видеодиктантах» (VocaType): звучит фраза из мультфильма, ученик
печатает услышанное по буквам, затем звучит следующая фраза. У нас уже есть все части по отдельности: плеер
YouTube с фразами по таймкодам (Шэдоуинг), ячейки для букв и сверка ответа (Just to Listen), проверка ролика через
oEmbed (Cartoon World). Видеодиктант собирает их в новый раздел.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Где у ученика | Карточка «Видеодиктант» в «Практике» → «Аудирование», сразу после Cartoon World | Владелец не определился; выбран самый короткий путь. Домашка и живой урок — следующими этапами |
| Как устроен | Отдельный раздел по образцу Шэдоуинга (вариант Б) | См. «Отвергнутые варианты» |
| Откуда фразы | Методист ведёт уроки в web-admin «Библиотека → Видеодиктант» | Как у Шэдоуинга: правки без разработчика |
| Какие ролики | Только официальные каналы правообладателей, встраивание включено | Условия YouTube; список кандидатов — `official-cartoons-youtube-2026-11-18.csv` (796 роликов Disney, Nickelodeon, Cartoon Network) |
| Что печатает ученик | Всю фразу или только пропуски, если методист их отметил | Пропуски нужны A0–A1: целая фраза мультика им не по силам |
| Монеты, квоты, домашка | В первой версии нет | Минимальная версия; см. «Не входит» |

### Отвергнутые варианты

- **А. Режим внутри Cartoon World.** Каталог мультиков приходит из html-прототипа методиста, а фразы пришлось бы
  вести в админке: два источника правды на одно видео. Движок Cartoon World сверяется с оракулом прототипа, и новый
  режим внутри него ломает принцип «порт почти дословно».
- **В. Режим внутри Шэдоуинга.** Одна таблица и один редактор, но Шэдоуинг уже на проде, его фразы до 25 секунд и
  рассчитаны на оценку произношения. Диктанту нужны фразы до 12 секунд, точность 0,1 с и пропуски — пришлось бы
  менять правила живого раздела.

## Права (обязательные ограничения)

1. Ролик играет только официальный встроенный плеер YouTube (`youtube-nocookie.com`, IFrame Player API).
   Управление — только методами API: `seekTo`, `playVideo`, `pauseVideo`, `setPlaybackRate`.
2. Поверх плеера ничего не кладём: поле ввода, подсказки и итог — под плеером.
3. Ролики не скачиваем, звук не записываем и не распознаём: для распознавания пришлось бы скачать звук.
4. Субтитры YouTube программой не забираем (официальный `captions.download` отдаёт их только владельцу ролика).
   Текст фраз методист вставляет из панели «Показать текст видео» или пишет сам — как сейчас у Шэдоуинга.
5. В админке при сохранении видно, чей канал (oEmbed `author_name`), а ролик с выключенным встраиванием сохранить
   нельзя. Официальность канала решает методист: автоматического списка «официальных» нет.
6. Обложка карточки — наша иллюстрация (ячейки букв и значок плеера), без кадров мультфильмов.

## Ученик (jts-web-app)

### Путь

1. «Практика» → «Аудирование» → карточка «Видеодиктант» → экран `?screen=video-dictation`.
2. Список уроков: уровень сверху (как строка `.pk-cap`, по умолчанию уровень ученика), карточка урока —
   превью YouTube (`i.ytimg.com/vi/<id>/mqdefault.jpg`, как в админке Шэдоуинга), название, сериал, канал, «N фраз»,
   лучший результат.
3. Урок `?screen=video-dictation&lesson=<slug>`:
   - сверху плеер 16:9 во всю ширину колонки;
   - кнопка «Начать» — первый `playVideo` идёт в обработчике нажатия (иначе iPhone не играет);
   - фраза играет от `start` до `end` и встаёт на паузу;
   - под плеером строка фразы: видимые слова текстом, пропуски — ячейками по буквам (вид ячеек Just to Listen);
     без скобок вся фраза — пропуски;
   - кнопки: «Ещё раз» (та же фраза), «Медленнее» (переключатель 1 ↔ 0,75, `setPlaybackRate`), «Подсказка»
     (открыть следующую букву), Enter или «Проверить»;
   - после верного ответа или после двух неудач фраза показывается целиком (цвет ячеек: ok / near / shown), через
     «Дальше» звучит следующая;
   - в конце итог: «С первого раза: 7 из 10», список фраз с отметкой, «Пройти ошибки заново» (только фразы не с
     первого раза, в этой же сессии), «К списку».
4. Прогресс урока виден в списке: лучший результат `ok / n`.

### Правила сверки

- Цель пропуска — буквы слов пропуска (`letters` из `src/practice/listen/compare.js`): регистр, пробелы, апострофы
  и знаки не набираются и не сравниваются, ячейки задают длину.
- Вердикт — `judgeWord` из `src/practice/listen/rules.js` над склейкой букв всех пропусков фразы: `ok`, `near`
  (1–2 буквы мимо — не засчитывается, «почти»), `bad`. Попыток две (`TRIES`), затем фраза показывается.
- «С первого раза» = `ok` с первой попытки без подсказок. Подсказки и вторая попытка дают «верно», но не «с первого
  раза».
- Варианты написания через `|` (как в Just to Listen) поддерживаются внутри скобок: `[colour|color]`. Ячеек столько,
  сколько букв в первом варианте.

### Плеер

- Загрузка API — общий `loadYouTubeApi`: функция переезжает из `src/screens/ShadowingPage.jsx` в
  `src/lib/youtube.js`, Шэдоуинг импортирует её оттуда (поведение не меняется).
- Остановка на конце фразы — опрос `getCurrentTime()` на `requestAnimationFrame`, пауза при `t >= end − 0,05`.
  Чистая логика («какую фразу играть, когда остановиться, что делать на ошибке плеера») — `player.js` без DOM, под
  vitest с поддельным плеером и часами.
- Ошибка ролика (`onError`) — плашка «Видео недоступно» со ссылкой «Смотреть на YouTube» и кнопкой «К списку»; урок
  в прогресс не пишется.

### Состояния экрана

- Загрузка — скелет списка; урок — скелет плеера и строки.
- Ручки нет (404) или уроков нет — «Раздел готовится» (как у Prepositions World).
- Сеть упала при загрузке урока — «Не удалось загрузить» и «Повторить».
- Тёмная тема — токены `--pk-*` вкладки «Аудирование»; ячейки — классы Just to Listen.
- Телефон: плеер на всю ширину, ячейки переносятся по словам, поле ввода прокручивается над клавиатурой.
- Доступность: у поля `aria-label` с номером фразы, вердикт в `aria-live="polite"`, видимый фокус, `prefers-reduced-motion`
  гасит анимацию ячеек.

### Файлы

- `src/practice/video-dictation/phrase.js` — разбор текста фразы: `[слово]` → пропуск, `a|b` → варианты.
- `src/practice/video-dictation/session.js` — машина урока вне React (как `ListenSession`): фраза, набор, подсказка,
  проверка, показ, следующая, итог; экран подписан через `useSyncExternalStore`.
- `src/practice/video-dictation/player.js` — управление фразой поверх объекта плеера.
- `src/practice/video-dictation/progress.js` — `createProgressStore` (`src/practice/progressStore.js`), модуль синка
  `videoDictation`, ключ `jts_video_dictation_v1` в `src/practice/practiceKeys.js`, merge «лучший результат урока».
- `src/screens/VideoDictationPage.jsx` + `src/screens/video-dictation/` (`LessonList`, `LessonRun`, `DictationLine`,
  `DictationResult`, `useVideoDictationData`); `lazyScreen` и ветка в `App.jsx`.
- `src/api.js` — `getVideoDictationIndex()`, `getVideoDictationLesson(slug)`.
- `src/screens/practice/practiceCatalog.js` — карточка `videoDictation: { nav: 'video-dictation', module: 'videoDictation' }`;
  `practiceTabs.js` — в `listening` после `cartoons`.
- Обложка — `node scripts/build-practice-card-covers.js videoDictation` (английский текст, без кадров мультиков).
- Луна: `src/lib/assistant/destinations.js`, `knowledge.js`, `prompt.js` — как у `wordhunt` (Луна открывает раздел
  и знает, что в нём).
- Тексты интерфейса — ru / kk / en.
- Каждая проверенная фраза — `recordSkill('listening', сПервогоРаза)` (`src/practice/skillStats.js`).

## Методист (web-admin)

- Раздел «Библиотека → Видеодиктант» рядом с «Шэдоуингом»: `src/app/feature/system/video-dictation/`
  (`video-dictation-list`, `video-dictation-form`, `video-dictation.routes.ts`), сервис и модель в `core/`.
- Список: название, сериал, уровень, канал, число фраз, «активен», «ролик доступен» (дата проверки), порядок
  перетаскиванием, кнопка «Перепроверить ролики».
- Форма:
  - ссылка на ролик → кнопка «Проверить»: бэкенд отвечает названием ролика, каналом и тем, включено ли встраивание;
    канал показывается крупно рядом с полем;
  - название, сериал, уровень (A0–C1), «активен»;
  - фразы: вставка текста панели YouTube или SRT/VTT разбирается `shadowing-captions.util.ts` (тот же разбор, что у
    Шэдоуинга) в строки «начало · конец · текст»;
  - у строки: «▶» (предпросмотр фразы в плеере формы, `YoutubePlayerLoader`), ±0,1 с у начала и конца, «начало = сейчас»
    и «конец = сейчас» по позиции плеера, удаление;
  - подсветка нарушений правил до сохранения (повтор правил бэкенда).
- Подсказка в форме: «Пропуски — в квадратных скобках: `I [want] to go [home]`. Без скобок ученик пишет всю фразу.
  Числа пишите словами».
- Тексты — ru / kk / en (локализация админки).

## Бэкенд

Модуль `videodictation` — по образцу `modules/shadowing` (сущность, репозиторий, правила без Spring, сервис, DTO,
два контроллера).

### Таблица (миграция — следующий свободный номер на момент PR)

`video_dictation_lessons`: `id`, `slug` (уникальный, создаётся сервером один раз: латиница из названия + дефис +
5 случайных знаков, как у Шэдоуинга), `title`, `series`, `video` (11 знаков), `channel_name`, `channel_url`,
`level`, `segments` (jsonb: `[[start, end, text], …]`), `order_index`, `active`, `available` (по умолчанию true),
`checked_at`, `created_at`, `updated_at`.

### Правила (`VideoDictationRules`)

- Фраз 1–60, по возрастанию начала, без наложений.
- `0 ≤ start < end`, длина фразы 0,5–12 с, точность 0,1 с (сервер округляет).
- Текст 1–120 символов; скобки парные, не вложенные, внутри скобки непустое; в пропуске только латинские буквы,
  апостроф, дефис, пробел и `|`; цифры в пропусках запрещены (ячейки их не показывают).
- Ролик: идентификатор из ссылки (тот же разбор, что `ShadowingRules`); при сохранении — oEmbed: 401 (встраивание
  выключено) или 403/404 (удалён, закрыт) → 400 с понятным текстом; канал и ссылка на канал пишутся из ответа.

### Ручки

Ученик (Bearer):

- `GET /mobile/video-dictation` → `{ "lessons": [ { "slug", "title", "series", "level", "video", "channel",
  "phrases": 12, "orderIndex": 3 } ] }` — только `active && available`, по `order_index`.
- `GET /mobile/video-dictation/{slug}` → то же + `"segments": [[12.4, 14.9, "I [love] jumping in [muddy] puddles!"]]`;
  нет или скрыт — 404.

Админ (роли `ADMIN`, `CONTENT_MANAGER` — как у `/admin/shadowing`):

- `GET /admin/video-dictation`, `GET /admin/video-dictation/{id}`, `POST`, `PUT /{id}`, `DELETE /{id}`,
  `PUT /admin/video-dictation/order`.
- `GET /admin/video-dictation/video-info?video=<ссылка>` → `{ "video", "title", "channel", "channelUrl",
  "embeddable" }`; ролик удалён или закрыт — 404.
- `POST /admin/video-dictation/recheck` — oEmbed по всем урокам (`CartoonsAvailability.check`, бин используется как
  есть, код Cartoon World не меняется); недоступные получают `available = false`, ответ — сколько скрыто.

Для `video-info` нужен `author_name`, которого `CartoonsAvailability` не отдаёт: свой маленький клиент oEmbed в модуле
(таймаут 5 с, без ключей).

## Порядок выката

1. Бэкенд (develop): таблица, ручки. Без уроков ученик видит «Раздел готовится».
2. Админка: методист заводит 3–5 уроков на деве.
3. Сайт: карточка и экран. Порядок безопасен в любую сторону: сайт на 404 показывает «Раздел готовится».
4. На прод — только по команде владельца, как обычно.

## Не входит в первую версию

- Домашняя работа и результат у преподавателя.
- Монеты и квоты.
- Перевод фразы и тап по слову.
- Режим на живом уроке.
- Автоматическая ночная перепроверка роликов (только кнопка и проверка при сохранении).
