# Cartoon World — раздел «Практики»: мультфильмы с миссиями, материал из админки

Дата: 22.10.2026. Источник — прототип методиста «Cartoon World» (standalone html, 13 МБ, прислан в чате
22.10.2026). Шаблон — Prepositions World (`2026-10-22-prepositions-world-design.md`): прототип заливается в
web-admin целиком, бэкенд кладёт данные в MinIO, сайт берёт их по API, движок прототипа — почти дословно в
Shadow DOM.

## Что это

Библиотека из 726 YouTube-видео (A0–C1, дети / подростки / взрослые): поиск, аудитория, уровни, тема,
длительность, полки по уровням. Под видео — **миссия**: переписка с персонажем на 10 ходов (ответы персонажа
написаны заранее и выбираются по ключевым словам ответа, без ИИ), подсказки, слова, заготовки фраз, итог
«Миссия выполнена».

Данные прототипа — JS-литералы `window.CARTOON_LIBRARY` (5), `CARTOON_DATA` (3 открытых фильма), `CARTOON_CATALOG`
(110 строк), `CARTOON_EXTRA` (608), `CARTOON_MISSIONS` (726, 6.3 МБ текста), `MISSION_BG` (10 JPEG по темам, 4.8 МБ).
Движок (~67 КБ JS) сводит четыре источника в один список (`normalize*`).

## Решения владельца (22.10.2026)

- Отдельный раздел; материал транслируется с бэкенда; заливка прототипа целиком (как «Предлоги»).
- Видео «для взрослых» (123) и с предупреждением (64) **видны всем**, с плашкой — как в прототипе.
- Нерабочие видео (удалены, приватные, запрещено встраивание) **отсекает бэкенд при заливке** (YouTube oEmbed),
  ученик их не видит, админ видит список; плюс «Перепроверить» без перезаливки.
- Миссии — **как в прототипе** (офлайн, ключевые слова), с одной починкой: подсказка, переписанная дословно,
  принимается даже короче минимума слов (сейчас 7563 из 13641 подсказок короче минимума).
- Фильтр длительности **оставить как есть** (длительность известна у 41 видео).
- Реализация — без субагентов, ревью ветки в конце.

## Backend — модуль `cartoons`

- `POST /admin/cartoons/upload` (ADMIN, multipart `file`, до 64 МБ): литералы через `shared/util/JsLiterals`
  (без исполнения JS). Ошибка — отказ всей загрузки: нет `CARTOON_MISSIONS` или `MISSION_BG`, ни одного
  источника видео, уровень вне A0–C1, YouTube-id не по шаблону `^[A-Za-z0-9_-]{11}$`, повтор id видео, фон не JPEG.
  Предупреждения: у видео нет миссии или она без ходов (панели миссии не будет), у темы нет фона.
- Проверка видео — `CartoonsAvailability`: oEmbed `https://www.youtube.com/oembed?format=json&url=…watch?v=<id>`,
  8 параллельно, таймаут 6 с. 200 — живое; 400/401/403/404 — нерабочее (удалено, приватное, встраивание
  запрещено); сбой сети / 5xx / 429 — «не проверено», видео НЕ прячем (предупреждение со счётом).
- Хранилище `CartoonsStorageService` (как `ListenStorageService`): `cartoons/current/index.json`,
  `cartoons/current/missions.json`; фоны — `cartoons/media/<sha24>.jpg`, `Cache-Control: immutable`, публичный
  бакет. Общий `modules/practice` не трогаем (его меняет открытый PR «Предлогов»).
- `index.json`: `{release, uploadedAt, checkedAt, library, data, catalog, extra, bg: {тема: URL}, unavailable:
  [{id, yt, level, title}]}` — источники как в прототипе, движок сводит их сам.
- Порядок: разбор → проверка видео → фоны → `missions.json` → строка релиза → `index.json` → сброс кэша → уборка
  фонов (кроме прошлого релиза). Одна загрузка за раз (409). Сбой после строки релиза её удаляет.
- `POST /admin/cartoons/recheck` — перепроверить видео текущего `index.json` и переписать `unavailable`.
- Ученику (Bearer): `GET /mobile/cartoons` — индекс; `GET /mobile/cartoons/missions/{id}` — одна миссия
  (~8 КБ). Кэш в памяти до загрузки. До первой загрузки — 404.
- Таблица `cartoons_releases` (мета; номер миграции сверить перед мержем).

## web-admin — страница «Cartoon World»

Как «Prepositions World»: загрузка, релиз (видео, миссии, нерабочие), предупреждения, история, обрыв прокси →
перечитать релиз. Плюс список нерабочих видео (уровень, название, ссылка на YouTube) и кнопка «Перепроверить».

## Сайт

- Экран `?screen=cartoons` (`src/screens/CartoonsPage.jsx`), баннер — вкладка «Аудирование» после Just Listen It.
- Движок `src/practice/cartoons/engine.js` — `mountCartoons(root, cfg)`, скрипт прототипа почти дословно.
  Отличия: данные из `cfg.index`; миссия догружается `cfg.loadMission(id)` при открытии видео; браузерная
  проверка 726 обложек (`Avail`) убрана — вместо неё `index.unavailable`; плеер — `youtube-nocookie.com`,
  `YT.Player` получает элемент, а не id (элемент в тени `getElementById` не найдёт); свой роутер вместо
  `location.hash`; язык — приложения (ru/kk/en, английские строки дописаны), переключателя RU/KZ и шапки с
  логотипом нет; `document.title` не трогаем; шрифт сайта; починка подсказок.
- Прогресс — модуль синка `cartoons`: `{missions: {id: {turns: [{t, p, w}], done, at, u}}}`, merge: `done` — ИЛИ,
  ходы — у копии с бо́льшим `u` (время последней правки). Черновик ответа — только на устройстве
  (`jts_cartoons_drafts`). Пройденная миссия — `recordSkill('writing', true)`.
- Тесты: урезанная копия прототипа (`scripts/cartoons/make-fixture.js`), оракул прототипа в jsdom
  (`scripts/cartoons/extract-oracle.js`: полки библиотеки при наборе фильтров и `pickPath` на ходах миссий),
  `engine.test.js`, e2e: библиотека → видео (YouTube заглушён) → миссия до конца → перезагрузка.

## Выкатка

Три PR: backend → web-admin → сайт; без заливки сайт пишет «Раздел готовится». Перед первой заливкой:
лимит тела (13 МБ) и таймаут прокси (проверка 726 видео ~30–60 с). Заливает владелец.
