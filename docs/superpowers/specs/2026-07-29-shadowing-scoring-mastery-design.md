# Shadowing — оценка произношения, синхрон-режим и мастерство

Дата: 2026-07-29
Ветка: `feat/shadowing-scoring` (поверх `feat/practice-shadowing`, PR #123)
Статус: дизайн одобрен, готов к плану реализации

## Цель

Довести тренажёр Shadowing (базовый экран уже в PR #123) от «прослушай → повтори →
сравни» до настоящей методики shadowing. Закрываем 6 из 7 разрывов, найденных при
разборе техники (кроме №7 — группировки в клипы 30–90с, отложена):

1. Одновременное проговаривание (синхрон) — говорить поверх играющего аудио.
2. Обратная связь по просодии.
3. Оценка произношения (ASR).
4. Сохранение записей между перезагрузками.
5. Цикл/мастерство урока.
6. «Слепой» (parrot) режим без текста.

## Зафиксированные решения

- **Синхрон (№1):** только **пофразно**. Фраза играет, микрофон пишет одновременно,
  задержка ~1с; по концу фразы — стоп и оценка. Сквозного прогона всей речи нет.
- **Просодия (№2):** **prosody-балл Azure + послово-тепловая карта** (accuracy по
  словам из эталон-режима Azure). Питч-кривая оригинала недоступна — см. Ограничения.
- **Хранение (№4):** **IndexedDB локально** (аудио + лучший балл на фразу). В аккаунт
  синкается только множество **освоенных** id фраз (существующий механизм).
- **Разбор Claude:** **да** — короткий совет (1–2 фразы) по данным Azure, best-effort.

## Ключевое ограничение

Референс-аудио играет внутри **YouTube-iframe**; доступа к его PCM-семплам нет
(cross-origin). Поэтому:
- Нельзя наложить питч-кривую «ты vs оригинал» — не обещаем этого в UI.
- Синхрон-режим пишет только микрофон (не микс с оригиналом) — этого достаточно для
  оценки собственной речи Azure'ом.

## Архитектура

Экран уже ~640 строк; чтобы не раздувать его скорингом/синхроном/мастерством,
выделяем модули с одной ответственностью.

### Новые файлы

- `src/practice/shadowing/recordings.js` — IndexedDB-обёртка. Object store `takes`,
  ключ `segId` (`${lessonId}_${index}`), значение `{ blob, score, ts }`. Async API:
  `saveTake(segId, blob, score)`, `getTake(segId)`, `getScore(segId)`,
  `getLessonScores(lessonId) → Map`, `clearLesson(lessonId)`. Гард на отсутствие
  IndexedDB (SSR / приватный режим) → no-op, экран не падает.
- `src/practice/shadowing/mastery.js` — чистое. `MASTERY_THRESHOLD = 80`.
  `isPhraseMastered(score)`, `lessonMastery(scoresMap, total) → { mastered, pct }`.
- `src/practice/shadowing/assessClient.js` — клиент. `assessTake(wavBlob, refText)`
  → POST `/api/shadowing/assess` (multipart), нормализует ответ в
  `{ overall, accuracy, fluency, prosody, words: [{ word, accuracy, error }], tip, mock }`.
- `src/app/api/shadowing/assess/route.js` — сервер. Принимает `{ audio (wav), text }`,
  вызывает `assessAgainstReference` (или `mockPronunciation`), затем best-effort
  Claude-совет (только по реальным баллам), отдаёт JSON. Работает и для гостя.
- `src/components/shadowing/PhraseScore.jsx` — карточка результата: кольцо overall,
  prosody-балл, тепловая карта слов, совет Claude, кнопка «Записать снова».
- `src/components/shadowing/usePlayerSync.js` — хук: вынести из экрана таймер плеера,
  `activeIdx`, `stopAt`, `loop`, `clearInterval` в cleanup.
- Стили: расширить `src/shadowing.css` (классы результата/мастерства/режимов).

### Правки существующих

## Как решается каждый разрыв

1. **Синхрон (пофразно).** Тумблер режима. В «Синхрон»: тап по фразе → `seekTo(start)`,
   `playVideo()` (НЕ пауза) + старт записи микрофона; по достижении `end` (в тайм-петле)
   → стоп записи → на оценку. Лупа доступна. В «По очереди» — как сейчас (пауза + запись).
2. **Просодия.** `PhraseScore` рисует prosody-балл + подсветку слов фразы по
   `words[].accuracy` (≥80 зелёный / 60–79 жёлтый / <60 красный), `error='Omission'`
   — серый/зачёркнутый. Питч оригинала не обещаем.
3. **Оценка.** `assessAgainstReference(wav, phraseText)` → overall/accuracy/fluency/
   prosody + words. Без Azure — `mockPronunciation()` + пометка «оценочно», карта слов
   не строится (нет данных) — показываем только числа.
4. **Сохранение.** `recordings.js`: после записи сохраняем blob + лучший балл;
   «Твоя запись» и «Сравнить» играют из IndexedDB; переживает перезагрузку.
5. **Мастерство.** Лучший балл на фразу — **локально** (IndexedDB). Фраза «освоена»
   при `≥80`; мастерство урока = % освоенных, считается на устройстве. Синкнутое
   множество остаётся «попытка сделана» (см. Хранение) — семантику НЕ меняем, чтобы без
   Azure (mock, балл ниже порога) прогресс не застревал. Шапка урока показывает кольцо
   «освоено X / N» (локально); карточка Практики — «попыток X / N» из синка + кольцо
   мастерства, если локальные баллы есть. Повтор-до-освоения закрывает «3–4 сессии»
   метода без искусственного счётчика дней.
6. **Слепой режим.** Тумблер «Скрыть текст»: `.sh-seg__txt` скрывается (остаются номер,
   таймер, кнопки). Тепловая карта после оценки показывается всё равно (это фидбек).

## Поток данных

```
MediaRecorder(webm) → blobToWav16kMono → POST {wav, refText}
  → /api/shadowing/assess
      → assessAgainstReference (Azure PA, эталон) | mockPronunciation
      → [если реальные баллы] Claude tip (best-effort)
      → JSON {overall, prosody, words[], tip, mock}
  → PhraseScore (кольцо + карта слов + совет)
  → recordings.saveTake(segId, blob, bestScore)   (IndexedDB, локально)
  → markSegmentDone(segId) → синк аккаунта (попытка сделана)
  → пересчёт мастерства урока (локально, из лучших баллов)
```

## Хранение и синк

- **IndexedDB (локально):** аудио-записи + лучшие баллы. Мастерство считается отсюда
  внутри экрана.
- **Аккаунт (существующий синк, `'shadowing'` уже в `PRACTICE_MODULES`/`DONE_MODULES`):**
  множество id фраз, по которым сделана **попытка** (записана ≥1). Семантику НЕ меняем —
  прогресс синкается кросс-девайс и не застревает без Azure (mock).
- **Мастерство — локально** (из лучших баллов в IndexedDB): фраза освоена при ≥80.
  Карточки Практики читают синкнутое множество попыток (синхронно, кросс-девайс) и
  накладывают кольцо мастерства, если есть локальные баллы. Аудио и сырые баллы — только
  на устройстве (согласуется с выбором IndexedDB).

## Ограничения (фиксируем в UI и коде)

- Питч-кривая «ты vs оригинал» невозможна (YouTube). Даём Azure-балл + послово-карту.
- Без `AZURE_SPEECH_KEY/REGION` баллы mock, помечены «оценочно»; Claude-совет — только
  по реальным баллам; тепловой карты в mock нет.
- Кросс-девайс синкается только «попытка сделана»; мастерство и сами записи локальны
  (не переносятся между устройствами).
- Гость работает: скоринг доступен (mock/реальный), синк освоенного — no-op без токена,
  записи — в IndexedDB.

## Обработка ошибок

- Нет микрофона / отказ → текущая заметка `sh-note--err` (уже есть).
- Azure недоступен/таймаут → mock, помеченный «оценочно», UI не падает.
- Claude недоступен → просто нет совета (баллы и карта остаются).
- IndexedDB недоступен (приватный режим) → записи не сохраняются, скоринг работает,
  мастерство живёт в памяти сессии; без падений.
- WAV-энкодинг вернул null (пустая/битая запись) → «не расслышал, запиши ещё раз».

## Тестирование

Тест-раннера в проекте нет (Playwright + node-специи).
- **node-юнит:** `mastery.js` (пороги, %), нормализатор `assessClient` (форма ответа),
  парсер `assessAgainstReference` на фиксированном Azure-JSON (послово, errorType).
- **Playwright:** синхрон-режим не тормозит уход с экрана (`clearInterval`, видео стоп);
  слепой режим прячет текст; mock-скоринг рисует кольцо (карты нет); сохранённая запись
  видна после reload (IndexedDB).
- `npm run build` (импорты/SSR), прогон `?screen=shadowing`.

## Вне объёма (YAGNI / позже)

- Разрыв №7: группировка фраз в клипы 30–90с.
- Питч-кривая оригинала (заблокировано YouTube).
- Облачное хранение аудио (Azure Blob) — выбрано локальное.
- Кросс-девайс перенос самих аудио-записей.
- Явный счётчик «сессий 1..4» (мастерство заменяет).
