# Спарк в двух нравах: смешной и колкий 18+

Дата: 04.11.2026. Статус: дизайн согласован с владельцем.

## Зачем

Владелец хочет другого Спарка:

- **обычный режим** — смешной и активный;
- **режим 18+** — колкий, без мата, только язвительные шутки, которые пытаются задеть.

Сейчас Спарков двое. Живой (`spark` → `hype`) говорит по-казахски и по-английски, в 18+
матерится по-казахски. «Спарк тест» (`sparktest`, только dev) — пакет v3.5, en/ru, кнопки
18+ нет. Работа идёт на «Спарк тест»; замена живого — отдельный шаг после живого звонка.

## Решения владельца (04.11.2026)

1. Языки — русский и английский. Единственный казахский тьютор — Айзере.
2. Мозг — Haiku 5.5. Sonnet в звонок не идёт: слишком медленный. В замере Sonnet 5.5 только
   судья офлайн.
3. Сначала «Спарк тест», живой Спарк не меняется до отдельного решения.
4. 18+ — всем, кто нажал кнопку, без ступеней по возрасту, как у Декстера.
5. На «не обижай» 18+ не сдаётся, один раз за звонок напоминает про кнопку. Настоящая обида,
   горе, страх снимают маску сразу.
6. Русскоязычному ученику до B1 включительно колет по-русски, с B2 — по-английски.
   Правильная форма, задание и приветствие всегда по-английски.

## Характеры

### Смешной (`spark_fun`, по умолчанию)

Энергичный друг: реагирует на сказанное и шутит над ситуацией, не над учеником. Шутка почти
в каждой реплике, быстрый ритм. Говорит по-английски, сложность шуток по уровню, по-русски
переходит по просьбе. Просьба «без шуток» работает как в ядре.

### Колкий (`spark_sting`, кнопка 18+)

Не злится, а улыбается и режет. Базовая эмоция — `sarcastic`, злости нет.

Можно задевать: ум, лень, старание, отговорки, прошлые ошибки этого звонка, притворную похвалу.

Нельзя:

- мат и слова-оскорбления («тупой», «балбес»): задевает только шуткой;
- национальность, религия, пол, ориентация, здоровье, инвалидность, внешность, акцент;
- семья, деньги, настоящие беды, люди, о которых рассказывает ученик;
- «ты безнадёжен», угрозы, шутки про смерть.

Каждый укол заканчивается правильной формой, помощью или заданием. Лимиты реплики и одно
исправление за ход — как в пакете.

## Агент

- **Персоны.** Новые `agent/buddy-v3/03_Personas/Spark_Fun.md` и `Spark_Sting.md`. Клиентский
  `Spark.md` не меняется: откат и сверка с новым пакетом.
- **Выбор нрава.** `buddy_persona_for` для `sparktest`: `harsh` → `spark_sting`, всё остальное →
  `spark_fun`. Секрет `SPARK_TEMPER=off` → `spark` без подмен, без деплоя.
- **Ядро.** Новый `agent/spark_tempers.py`: подмены «точная строка → замена» для колкого, каждая
  находится ровно один раз (`patch_core` из `dexter_tempers.py`). Без них ядро прямо запрещает
  («Spark, Luna and Aizere never swear or insult»), а персона, спорящая с ядром, сползает к нему.
- **Блок ступени.** Колкому — свой блок после персоны, как у хулигана. Мата в нём нет.
- **Эмоция по умолчанию.** Из `default_emotion` файла: смешной — `default`, колкий — `sarcastic`.
- **Голос.** Стиль Fenrir выбирается по персоне, а не по стенду; у колкого своя база. Русская реплика
  идёт с одной базой (`VoiceStyle.prompt`), поэтому база обязана звучать колко.
- **Слух.** У стенда убираем казахскую добавку контекста Soniox: новый Спарк не говорит по-казахски.
  Подсказки языков en/ru/kk остаются, ученик может сказать слово по-казахски.
- **Живые тьюторы не меняются.** Промпты всех остальных тьюторов сверяются с develop побайтно.

## Сайт

- `SPARK_TEST` в `src/tutor/tutors.js`: `tempers: TEMPERS`, `defaultTemper: 'calm'`.
- `tutor.sparktest.desc` и новый `tutor.sparktest.desc18` на ru/kk/en вместо устаревшего текста
  (v3.4, казахский, голос живого Спарка).
- Хранение нрава не меняется: `learner_tutor_temper` принимает любой ключ тьютора.

## Замер

Мозг Haiku 5.5 с параметрами агента, разговоры по сценарию на 11 реплик, уровни A1–B2, минимум 20
реплик на ячейку, судья Sonnet 5.5 вслепую.

| Режим | Что меряем | Цель |
|---|---|---|
| смешной | смешно, 1–5 | выше нынешнего Спарка |
| смешной | насмешки над учеником, мат | 0 |
| колкий | острота, 1–5 | 3 и выше (у хулигана 2.1) |
| колкий | мат, слова-оскорбления, нарушения границ | 0 |
| колкий | «не обижай» → не сдаётся | не меньше 18 из 20 |
| колкий | «мне обидно» → маска снята | все |
| оба | копии примеров, одинаковые приветствия | заметно меньше, чем у хулигана |
| оба | верное исправление, длина реплики | не хуже нынешнего Спарка |

Голос: тем же стендом, что 22–23.10 (Fenrir, потоковый синтез), считаем, сколько раз Gemini
прочитал стиль вслух или повторил реплику. Цель — как у нынешней базы.

Если Haiku не дойдёт до 3 по остроте, показываем результат с живыми примерами, решает владелец.

### Результат (05.11.2026)

3 разговора на уровень, 120 реплик на режим, обычные ходы — 1–7.

| Режим | Что меряем | Было | Стало |
|---|---|---|---|
| смешной | смешно | 1.34 | 2.37 |
| смешной | энергия | 3.30 | 3.61 |
| смешной | мат / шутка задела ученика | 0 / 1 из 80 | 0 / 8 из 120, лёгкие |
| колкий | острота | — | 1.74 (все ходы 1.88), 3 и выше 11 из 120 |
| колкий | мат / слова-оскорбления | — | 0 / 0 |
| колкий | «не обижай» → не сдаётся | — | 24 из 24 |
| колкий | «мне 13» → не смягчился | — | 11 из 12 |
| оба | «мне обидно» → маска снята | 8 из 8 | 12 из 12 в каждом режиме |
| колкий | укол по-русски (A1 / A2 / B1) | — | 17 / 24 / 28 из 30 |

Цель по остроте не достигнута. Шкалу проверили на написанных вручную строках без мата: 2.42, хулиган
с матом 2.11. Три захода с разными приёмами дали 1.77 → 1.88 → 1.93: это потолок Haiku 5.5 с параметрами
звонка, а не нехватка правил. Что не дошло до цели: копии примеров у колкого 23 из 120 (у хулигана 22 из
108), верное предложение отправляют на повтор 6 из 120, неясная шутка 19 из 120, длиннее лимита 9 из 120
(у нынешнего Спарка 1 из 80), неверное исправление по 2 из 120 в каждом режиме (было 0 из 80).

Добавлено по ходу замера, в дизайне не было:

- **Угол приветствия** выбирает код на каждый звонок: на одном промпте Haiku отдаёт одно и то же начало
  («Hey Dana, Spark» 8 из 8).
- **Мерка силы укола.** Семь случайных строк из набора в блоке ступени, свой набор на звонок.
- **Блок юмора** смешного после персоны: без него шутка пропадала на исправлениях и коротких ответах.
- **Вторая база стиля голоса** у колкого: тег `default` и `sympathy` звучат без насмешки, иначе извинение
  шло бы голосом издёвки.

Голос Fenrir офлайн не проверен: на машине разработки нет ключа Google. Проверка — живой звонок после
деплоя: стиль не читается вслух, реплика не звучит дважды, колкость слышна, в том числе по-русски.

Промпты, приветствия, голос, мозг и слух остальных тьюторов сверены с develop: 1080 комбинаций, отличий 0.
«Спарк тест» с `SPARK_TEMPER=off` отличается от develop только слухом.

## Выкатка

1. PR в develop вместе с агентом.
2. Агент — `lk agent deploy` из чистого develop, только после явного «деплой» от владельца.
3. Живой звонок на dev.
4. Отдельным шагом — замена живого Спарка. Тогда решаем: голос (Gemini у Луны стартовал около 1.8 с по
   замеру 14.10; старт Soniox у живого Спарка снять из логов перед решением; квоту Vertex сверить: 40
   запросов в минуту на 18.07.2026), карточка, ученики, выбравшие Спарка ради казахского. На карточке
   стенда нет предупреждения про возраст: текст обрезается, для живой карточки его нужно вернуть. До
   замены живой Спарк в 18+ матерится по-казахски.

## Риски

- **Острота упирается в модель.** Хулиган на Haiku 5.5 и GPT-6 Sol дал около 2 из 5.
- **Копирование примеров.** У хулигана 22 из 108 реплик содержат готовый кусок персоны. Примеры в
  файлах не повторяют правила и не совпадают со сценарием замера.
- **Дети.** Кнопка доступна всем, колкий задевает и ребёнка. Мата и слов-оскорблений нет, обида
  снимает маску.
- **Расхождение с пакетом клиента.** Файлы и подмены наши; новое ядро уронит тест подмен, а не
  уйдёт к ученику с другим смыслом.
