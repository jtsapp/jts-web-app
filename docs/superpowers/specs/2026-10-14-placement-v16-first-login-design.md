# Тест уровня v16 при первом входе — дизайн

14.10.2026. Источник: комплект методиста (JTS Placement v16 Phase 3.1) и голосовое руководителя.

## Цель

Новый ученик после регистрации (или первого входа в выданный менеджером аккаунт) попадает сразу на «Главную»:
тур → верхний блок «Главной» (роадмап А → Б) закрыт блюром и просит пройти тест → тест v16 → маршрут (формат) →
«Главная» с открытым роадмапом и подробным отчётом теста.

## Решения владельца (14.10)

1. Тест v16 заменяет прежний тест уровня (`src/practice/placement/`, экраны `test-intro` / `test`).
2. Анкета целей v16 заменяет анкету General English (`ge-onboarding`) в потоке первого входа. Правка цели с
   «Главной» остаётся прежним экраном (режим edit).
3. Тест — всем ученикам при первом входе. Уровень аккаунта тест ставит, только если он пуст: тарифный уровень не
   трогаем (решение 30.09).
4. Закрыт только блок роадмапа; остальная «Главная» и меню работают.
5. Формат обучения (сам / группа / индивидуально) — существующий экран «Маршрут» (`ge-route`) сразу после теста.
6. Говорение — как SpeakSpin: тема, подготовка, запись до 3 минут; распознаёт Azure, оценивает Sonnet.
7. Учившиеся до теста v16 (аккаунт создан до 15.10.2026, `createdAt` из `/user/me` —
   `src/placement/existingStudent.js`) тест не обязаны проходить (решение владельца 14.10: «не заставлять, а просто
   пусть на главной будет выходить как не пройденный»): роадмап не размывается. Анкеты GE нет — вместо блюра обычная
   карточка «Тест уровня не пройден» (`notTested`); блок цели есть — он на месте, под ним отметка «Тест уровня · Не
   пройден». Признак — дата, а не уровень: новый аккаунт от менеджера тоже приходит с тарифным уровнем.
8. Подход А: v16 встраивается как есть (same-origin iframe), наше — через крючки автора.

## Встраивание (подход А)

- Источник правды — `data/jtsplacement-v16.html` (правки контента — у автора, новая версия кладётся поверх).
- `node scripts/build-placement-v16.js` собирает `public/placement/v16/`:
  - вшитые base64 (картинки, шрифты, видео) → файлы `media/<sha1>.<ext>`;
  - записи с чужого CloudFront → `audio/<имя>.mp3` (скачивание идемпотентно);
  - точечные патчи, каждый обязан найтись ровно один раз (иначе сборка падает — новая версия автора не наложится
    вслепую): ключ localStorage с пространством профиля, стартовый язык из адреса, `APP_CONFIG` на свои адреса.
- Экран `?screen=placement` (`src/screens/PlacementPage.jsx`) — режим фокуса без меню, iframe
  `/placement/v16/index.html?lang=&ns=`. Мост (`src/placement/bridge.js`) на загрузке кладёт в окно iframe
  `JTSPlacementConfig` (onComplete, openLearning, navigate) и `JTSSpeakingBuddy` (start).
- Прогон v16 хранится в localStorage устройства под ключом с пространством профиля: другой ученик на том же
  устройстве не продолжит чужой тест. Выход из аккаунта чистит эти ключи.

## Говорение

`JTSSpeakingBuddy.start({placementSessionId, grammarLevel, readingLevel, listeningLevel})` открывает поверх iframe
окно `SpeakingTask`: тема по уровню (средний из LU/R/L), 60 с подготовки, запись до 180 с (WAV 16 кГц,
`useRecorder`). `POST /api/placement/speaking` — Azure (текст + произношение кусками) и Sonnet (уровень CEFR,
уверенность, четыре оси). Тему сервер берёт по `topicId` из своих данных. Лимит — общий дневной с SpeakSpin.
Пропуск — `reject`: v16 помечает говорение ошибкой и не зовёт окно снова. Говорение не входит в общий уровень (так
считает v16).

Своего итога у окна нет (правка 16.10.2026 по жалобе: окно минуту молчало без кнопок, а потом показывало уровень и
отзыв раньше остальных результатов). Пока идёт оценка — крутилка и «ничего нажимать не нужно»; оценка пришла — окно
сразу отдаёт её тесту и закрывается, а v16 открывает итог. Отзыв грейдера (`summary`/`strengths`/`improvements`, без
стенограммы) мост кладёт в ответ полем `feedback`, патч сборки сохраняет его в `validateSpeaking`, и он едет в
конверт (`skillResults.S.feedback`). Показывается в итоге рядом со всеми навыками: панель «Отзыв о говорении» на
экране результата v16 (крючок хоста `JTSHostSpeakingFeedback`, второй патч сборки) и блок в отчёте «Главной»
(`src/placement/speakingFeedback.js`).

## Сохранение

- `POST /api/placement/attempts` — конверт v16 (schemaVersion 1, source `jts_general_english_placement`), проверка
  формы и размера, upsert в `placement_v16_attempt` (миграция 0017) по (profile, attemptId).
  `GET /api/placement/attempts/latest` — последний конверт.
- Клиент после сохранения: уровень — `persistPlacementLevel`, только если в аккаунте пусто; профиль GE —
  `saveGeProfile` из ответов анкеты (`src/placement/geMapping.js`): purpose ← категория цели, target ← targetCEFR
  (если выше уровня, иначе рекомендованный), срок ← deadline, минуты ← studyAvailability.
- Сохраняем на `onComplete` (итог показан) и на `openLearning` (кнопка «продолжить»), второй ведёт на «Маршрут».

## «Главная»

- `homeTopState`: не заполнена анкета → `locked` (вместо `start` и `invite`). `needTest` / `needRoute` / `goal` —
  как были.
- `GeLockedRoadmap` — образец блока цели под блюром, по центру призыв и кнопка теста.
- Тур «Главной» стартует и без уровня, если блок закрыт; первый шаг — про закрытый блок.
- `PlacementReport` под верхним блоком — последний конверт: общий уровень, навыки (LU/R/L/S, подтверждено/нет),
  цель, приоритетные навыки, рекомендованные задания «Практики» (свои адреса экранов по типу, иначе — «Практика»).
