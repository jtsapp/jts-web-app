# «Изучено» и «хуже запомненные» «Словаря» на сервере — дизайн

Дата: 06.10.2026. Ветка `feat/vocab-progress-server` поверх
`feat/practice-progress-server` (#584, общее хранилище прогресса).

## Зачем

Счётчик «N изучено» (`jts.vocab.learned.v1`) и «хуже запомненные слова»
(`jts.vocab.misses.v1`) жили только в localStorage — одним блобом на всех
учеников браузера (`{ <uid>: {...} }`). На сервер не уходили вовсе: на другом
устройстве их нет, а при забитом кэшем каталогов хранилище запись молча
падала — «изучено» не росло.

## Как устроено

Два новых модуля `practice_state` на общем хранилище (`progressStore.js`):

- `vocabLearned`: `{ scopes: { <scopeId>: [ключи слов] } }`;
- `vocabMisses`: `{ words: { <ключ>: { word, ru, kk, misses, at } } }`.

Объекты, без слияния на сервере (replace) и без `merge` в хранилище: слово
можно снять из «изученных», ошибка снимается верным ответом — объединение
воскрешало бы снятое. Как у остальных объектов: память по владельцу, ответ
`hydratePractice` в память, побеждает сервер, если в загрузке не было действий.

Публичные функции `vocabLearned.js` / `vocabMisses.js` не меняются (параметр
`token` остаётся — по нему находится старый блоб).

**Перенос старого.** Блоб `jts.vocab.*.v1` держит записи по uid. Запись
текущего ученика переносится ОДИН раз, объединением с тем, что уже на сервере:
- гость (`anon`) — сразу;
- вошедший — только когда ответ сервера уже пришёл (`hasServerSnapshot()`),
  иначе перенос затёр бы серверное (replace). До этого экран показывает
  объединение памяти и старой записи, не записывая.
После переноса запись uid из блоба удаляется (пустой блоб — весь ключ).
`clearLocalPractice` старые блобы не трогает: там записи других учеников.

## Изменения вне модулей

- `practiceContract.PRACTICE_MODULES` + `vocabLearned`, `vocabMisses`
  (и белый список в `tests/practice-contract.spec.js`).
- `practiceSyncCore.OBJECT_MODULES` — оба (иначе `serializeForPush` сделал бы
  из объекта `{done: []}`).
- `practiceKeys` — ключи черновиков и события; `clearLocalPractice` чистит
  новые ключи.
- `progressStore.hasServerSnapshot()`.

## Тесты

- Существующий `vocabLearned.test.js` зелёный.
- Новые: квота — «изучено» и ошибки читаются обратно; снятие отметки и снятие
  ошибки работают; перенос гостя сразу; вошедший — перенос только после
  ответа сервера, объединением, с отправкой, запись uid удалена; чужая запись
  в блобе не трогается.
