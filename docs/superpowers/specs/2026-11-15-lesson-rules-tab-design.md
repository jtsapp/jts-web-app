# Правила обучения во вкладке «Уроков» — дизайн

Дата: 15.11.2026. Источник текста — документ школы «Правила обучения — Just to Study»
(`jts-rules.html`, прислан владельцем).

## Зачем

Правил на сайте не было: их знала только Луна (`src/lib/assistant/knowledge.js`, статья
«Правила обучения школы») и пересказывала по вопросу. Прочитать их ученику негде.

## Решение (согласовано с владельцем)

- **Где:** «Уроки» → вкладка «Правила», последней после «Отчётов». Только у ученика:
  преподаватель экран «Уроки» использует как рабочее место, правила для него не новость
  (так же устроены «Отчёты»). Видят все ученики, Self Study тоже — заморозка и абонемент
  касаются и их. Диплинк `?screen=lessons&tab=rules` (тот же разбор `tab`, что у отчётов).
- **Что:** документ целиком — шапка, четыре главные цифры, оглавление, 11 разделов с
  плашками, сводная таблица, заключение. Оглавление прокручивает к разделу кнопкой
  (`scrollIntoView`), а не якорем: адрес приложения не трогаем.
- **Язык:** по языку интерфейса, ru / kk / en. kk и en перевёл Claude, смысл и цифры те же;
  казахский — показать носителю до прода.
- **Не делаем:** кнопку на «Главной», пункт меню, ссылку в Feedback, хранение в админке.
  Если понадобятся — ведут на ту же вкладку.

## Устройство

- `src/screens/lessons/rules/rulesContent.js` — тексты трёх языков ОДНОЙ структурой:
  разделы из блоков `p` / `list` / `note` / `table`, выделение — `**…**`. Данные, а не html:
  иначе три копии разметки и стили документа против стилей сайта.
- `src/screens/lessons/rules/RulesTab.jsx` — рисует их, язык берёт из `useI18n().lang`.
- `src/lessonRules.css` — стили (префикс `lr-`), цвета — переменными блока; тёмная тема —
  блок генератора; телефон (≤560) — в том же файле.
- `LessonsPage.jsx` — вкладка `rules` у ученика; подпись `lessons.tabRules` во всех трёх
  словарях.
- Луна — строка в статье правил: «целиком — «Уроки» → вкладка «Правила»».

## Проверка

- vitest: вкладка есть у ученика и нет у преподавателя; `initialTab: 'rules'` открывает её;
  у трёх языков одинаковые id разделов, число пунктов, строк таблицы и тон плашек — перевод
  не потерял пункт.
- `npm run build`, `npm run lint`, ручной прогон `?screen=lessons&tab=rules` (десктоп,
  телефон, тёмная тема).
