# Just to Study Birge — веб (лента ученика) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Экран `?screen=birge` — лента веток студентов с формой «Новая ветка», ветками с комментариями, лайками, жалобами и показом решения автоматической модерации, по контракту бэкенда `/mobile/birge/**`.

**Architecture:** Чистые модули в `src/birge/` (клиент API, модель формы, смайлики, фото, подсветка, итог публикации, шаги проверки, вид карточки) под vitest; React-компоненты там же (форма, панель смайликов, карточка, лента, ветка, правила) и экран `src/screens/BirgePage.jsx` в общей оболочке кабинета `LearningLayout` (меню и общий колокольчик). Вход — пункт меню `birge`, ветка `handleNav`/`renderScreen` в `App.jsx` с ленивой загрузкой экрана, диплинк `?screen=birge&post=<id>` и ссылка уведомления `birge/<id>`. Модерацию делает бэкенд: веб только шлёт текст/фото и рисует ответ по таблице §3.3 спеки.

**Tech Stack:** Next.js 16 (App Router как оболочка SPA), React 19, JavaScript (.js/.jsx, без TS), глобальные CSS по разделам, vitest 2 + @testing-library/react + jsdom, Playwright.

**Источник правды:** спека `docs/superpowers/specs/2026-11-11-birge-community-design.md` (§3.3, §5.1, §5.3, §6, §7, §10) и прототип `docs/superpowers/specs/2026-11-11-birge-prototype.html`.

## Global Constraints

- Ручки ученика — `/mobile/birge/**`: `GET /posts?topic=&cursor=`, `GET /posts/{id}`, `POST /media` (multipart `file`), `POST /posts`, `POST|DELETE /posts/{id}/like`, `POST /posts/{id}/report`. Формы JSON — §5.3 спеки, имена полей менять НЕЛЬЗЯ (по ним параллельно пишутся бэкенд и web-admin).
- `decision`: `published | pending | tomorrow | hidden | rejected | feedback`.
- Темы: `GRAMMAR | SPEAKING | VOCABULARY | MOTIVATION | QUESTION` (подписи переводит веб).
- Коды причин: `PROFANITY | IMAGE_UNSAFE | INSULT | HARASSMENT | PLATFORM_COMPLAINT | TOXICITY | MASKED_SUSPECT | LINK_OR_CONTACT | SPAM | SOFT_CRITICISM | CAPS | AI_UNAVAILABLE | REPORTS` (кода `TOO_SHORT` нет).
- Длина: ветка без фото — от 6 символов текста (короче — «Опубликовать» неактивна, подсказка «Напишите хотя бы пару слов»; сервер на такое отвечает 400 `{messages:[…]}`, текст показываем); комментарий — любой длины от 1 символа. На 400 форма показывает текст сервера.
- Списки с курсором — `{items, nextCursor}`, `nextCursor: null` — конец.
- Ошибки бэкенда — `{messages: ["…"]}` + статус (`GlobalExceptionHandler`, так же их читает `rejectionText` в `src/api.js`); исключение — 429 `{ "error": "RATE_LIMIT", "retryAfterSec": 1200, "message": "…" }` → «Слишком часто — попробуйте через N мин». 429 бывает и у публикации, и у загрузки фото (`POST /media`, 30 загрузок в час, §3.7) — обе показывают одно и то же.
- PublishResponse: `{decision, post, risk, reasons, hits, removedMediaIds, feedbackId}`; поля `escalated` у ученика НЕТ — не читать. После автоотказа повтор с теми же `mediaIds` сервер принимает (переносит вложения своего отклонённого поста), а удалённые проверкой (`IMAGE_UNSAFE`) приходят в `removedMediaIds` — форма убирает только их, остальные фото остаются.
- Пост, скрытый по переполнению, автору приходит как `status: 'published'`, `hiddenReason: null`; лайк и ответ у него работают — веб ничего для него не гасит.
- На проде (`ai-tutor.justtostudy.kz`) у ученика `birge` — в `STUDENT_HIDDEN_ON_PROD` (`src/config.js`) рядом с `notifications`: колокольчика там нет, уведомления §6 не дошли бы (спека §11).
- Форма: «Что нового?», до 500 символов, автовысота, счётчик с 450; тема рядом с именем; фото до 4 с крестиком; «Дополните ветку» — до 4 продолжений.
- Смайлики: наборы `EMO` и `ECAT` прототипа ДОСЛОВНО; вставка в позицию курсора; панель после выбора не закрывается; «Недавние» — localStorage `jts_birge_recent_emoji`, 27 штук; 🤬 и 🖕 в наборе нет (сторожит тест).
- Фото: JPEG ≤ 1600 px по длинной стороне, качество 0.85; больше 10 МБ до сжатия — отказ; HEIC — где браузер открывает, иначе подсказка «сохраните фото как JPG».
- GIF НЕ делаем вовсе (ни панели, ни загрузки); кнопок «Демо» нет; переключателей роли и названия нет.
- Экран `?screen=birge[&post=<id>]`; шапка «Just to Study Birge», подзаголовок «Учимся вместе — сообщество студентов JTS»; колокольчик — общий кабинетный.
- Меню: пункт `birge` («Birge», метка new) в `NAV_FULL` сразу перед `feedback`, так же в `IELTS_SECTIONS`; у преподавателя и в тьютор-онли пункта нет; значок `diversity_3` файлом в `public/assets/home-v2/ico/`.
- Уведомление: `birge/<id>` → `{screen: 'birge', payload: {postId}}`, ветка выше общих веток по словам.
- 404 на `/mobile/birge/posts` → «Раздел скоро откроется».
- Бейджи своих непубличных: `pending`/`tomorrow` — «На проверке у модератора», `rejected` — «Отклонено», `hidden` по `reports`/`manager` — «Скрыто», `hidden` по `overflow` — без бейджа (автору такой пост и так приходит как `published`).
- Тексты ru / kk / en (дефолт ru); «Birge» и «Just to Study Birge» не переводятся.
- Стили: `src/birge.css` (префикс `.brg-`), мобильный слой `src/mobile/birge.css` (≤560px); новых `font-family` нет — `kk-font.css` не трогаем; тёмная тема — блоки раздела из `gen-dark-theme.js`, без чужих правок.

```js
import { API_BASE } from '../lib/apiBase.js'
import { reportUnauthorized } from '../lib/session.js'

// Клиент ручек ученика Birge — /mobile/birge/** (спека 2026-11-11 §5.1, формы §5.3). Свой, а не общие
// authGet/authPost из api.js: отказ 429 несёт retryAfterSec («попробуйте через N мин»), а общий разбор тела
// (rejectionText в api.js) оставляет от него только текст. Имена полей контракта не переименовываем: по ним
// параллельно пишутся бэкенд и web-admin.
//
// Адрес — из lib/apiBase.js, а не из api.js: компоненты в тестах мокают модули целиком, и импорт адреса из api.js
// падал бы на «нет такого экспорта» (та же причина, что записана в apiBase.js).

export class BirgeApiError extends Error {
  constructor(status, body) {
    // Отказы бэкенда — тело GlobalExceptionHandler { messages: ["…"] } (§5, так же их читает rejectionText в api.js);
    // исключение — 429 со своим телом { error, retryAfterSec, message } (§3.7, §5.3), отсюда запасное body.message.
    const text = (Array.isArray(body?.messages) ? body.messages[0] : null) ?? body?.message
    const message = typeof text === 'string' && text.trim() ? text.trim() : null
    super(message || `Ошибка сервера (${status})`)
    this.name = 'BirgeApiError'
    // 0 — запрос до сервера не дошёл (нет сети)
    this.status = status
    // RATE_LIMIT у 429 (§3.7); у остальных отказов поля error в контракте нет
    this.code = typeof body?.error === 'string' ? body.error : null
    this.retryAfterSec = typeof body?.retryAfterSec === 'number' ? body.retryAfterSec : null
    this.serverMessage = message
  }
}

async function request(path, token, { method = 'GET', json, form } = {}) {
  const headers = token ? { Authorization: `Bearer ${token}` } : {}
  // У multipart заголовок с границей ставит сам браузер — свой Content-Type его сломал бы.
  if (json !== undefined) headers['Content-Type'] = 'application/json'
  let res
  try {
    res = await fetch(`${API_BASE}/mobile/birge${path}`, {
      method,
      headers,
      body: form ?? (json !== undefined ? JSON.stringify(json) : undefined),
    })
  } catch {
    throw new BirgeApiError(0, { message: 'Нет связи с сервером.' })
  }
  if (!res.ok) {
    // 401 с токеном — возможно, кончилась сессия: разбор и плашку делает lib/session.js
    if (res.status === 401) reportUnauthorized(token)
    throw new BirgeApiError(res.status, await res.json().catch(() => null))
  }
  if (res.status === 204) return null
  return res.json().catch(() => null)
}

/** Список с курсором (§5.3): { items, nextCursor }, nextCursor: null — конец ленты. */
function page(data) {
  return {
    items: Array.isArray(data?.items) ? data.items : [],
    nextCursor: typeof data?.nextCursor === 'string' && data.nextCursor ? data.nextCursor : null,
  }
}

/** Лента: опубликованные ветки и свои непубличные, по 20, новые сверху. topic: null — все темы. */
export function listBirgePosts(token, { topic = null, cursor = null } = {}) {
  const query = new URLSearchParams()
  if (topic) query.set('topic', topic)
  if (cursor) query.set('cursor', cursor)
  const qs = query.toString()
  return request(`/posts${qs ? `?${qs}` : ''}`, token).then(page)
}

/** Ветка и комментарии: { thread, comments }. Нет доступа — 404. */
export function getBirgeThread(token, id) {
  return request(`/posts/${encodeURIComponent(id)}`, token).then((data) => ({
    thread: data?.thread ?? null,
    comments: Array.isArray(data?.comments) ? data.comments : [],
  }))
}

/**
 * Фото уходит на проверку сразу при выборе, а не при публикации (§3.1): { id, width, height }. Загрузки — под тем же
 * антиспамом, что публикации (§3.7): 429 с тем же телом, retryAfterSec разбирается так же.
 */
export function uploadBirgeMedia(token, blob, filename = 'photo.jpg') {
  const form = new FormData()
  form.append('file', blob, filename)
  return request('/media', token, { method: 'POST', form })
}

/** Публикация ветки или комментария → PublishResponse (§5.3). */
export function publishBirgePost(token, body) {
  return request('/posts', token, { method: 'POST', json: body })
}

/** Лайк (POST) или снять его (DELETE) → { liked, likes }. */
export function setBirgeLike(token, id, liked) {
  return request(`/posts/${encodeURIComponent(id)}/like`, token, { method: liked ? 'POST' : 'DELETE' })
}

/** Жалоба → { reports, hidden }. Свой пост — 403, повтор — 409. */
export function reportBirgePost(token, id, reason = null) {
  return request(`/posts/${encodeURIComponent(id)}/report`, token, { method: 'POST', json: { reason } })
}

/** 404 на ленте — бэкенд без раздела: экран пишет «Раздел скоро откроется», а не ошибку (§7). */
export const isSectionMissing = (err) => err?.status === 404
```

```js
// Модель формы «Новая ветка» и ответа (спека 2026-11-11 §5.1, §7). Лимиты — те же, что проверяет сервер: ученик
// узнаёт о них до отправки, а не отказом. Длина — в единицах UTF-16 (String.length): так же считает Java на
// бэкенде, и смайлик «весит» одинаково с обеих сторон.

export const TEXT_MAX = 500
export const PARTS_MAX = 4
export const PHOTOS_MAX = 4
// Счётчик символов появляется у самого предела: на коротком посте цифра «12/500» только отвлекает.
export const COUNTER_FROM = 450
// Ветка без фото — от 6 символов текста (§3.1, §5.1): короче сервер её не модерирует, а отклоняет 400. Комментарий
// («Да!», «+1») — норма, ему хватает одного символа.
export const THREAD_MIN_TEXT = 6

/** Пустой черновик: основной текст, продолжения ветки и фото ({ key, preview, status: uploading|ready, id }). */
export function emptyDraft() {
  return { text: '', parts: [], photos: [] }
}

/**
 * Вставка в позицию курсора. Позиция неизвестна или вне строки (в поле ещё не щёлкали) — в конец. Не влезает в
 * лимит — null: maxLength поля защищает только ввод с клавиатуры, а смайлик ставит код.
 */
export function insertAt(text, pos, insert, max = TEXT_MAX) {
  if (text.length + insert.length > max) return null
  const at = Number.isInteger(pos) && pos >= 0 && pos <= text.length ? pos : text.length
  return { text: text.slice(0, at) + insert + text.slice(at), pos: at + insert.length }
}

/** Счётчик поля: показывать ли (с 450) и не превышен ли предел. */
export function counter(text) {
  return { show: text.length >= COUNTER_FROM, len: text.length, over: text.length > TEXT_MAX }
}

export const photosUploading = (draft) => draft.photos.some((p) => p.status === 'uploading')
export const readyMediaIds = (draft) => draft.photos.filter((p) => p.status === 'ready').map((p) => p.id)
export const canAddPart = (draft) => draft.parts.length < PARTS_MAX
export const photoSlots = (draft) => Math.max(0, PHOTOS_MAX - draft.photos.length)

/**
 * «Опубликовать» доступна, когда ни одно фото не грузится и есть готовое фото или текст (§5.1): ветке без фото —
 * от 6 символов, комментарию — от одного.
 */
export function canPublish(draft, kind = 'thread') {
  if (photosUploading(draft)) return false
  if (draft.text.length > TEXT_MAX || draft.parts.some((p) => p.length > TEXT_MAX)) return false
  if (readyMediaIds(draft).length > 0) return true
  const len = draft.text.trim().length
  return kind === 'comment' ? len > 0 : len >= THREAD_MIN_TEXT
}

/**
 * Подсказка «Напишите хотя бы пару слов»: ветку начали, но текста меньше 6 символов и фото нет. Пустое поле —
 * без подсказки (его и так объясняет «Что нового?»); с фото, даже грузящимся, короткий текст допустим.
 */
export function tooShort(draft, kind = 'thread') {
  const len = draft.text.trim().length
  return kind === 'thread' && draft.photos.length === 0 && len > 0 && len < THREAD_MIN_TEXT
}

/**
 * Тело POST /mobile/birge/posts (§5.1). У комментария темы и продолжений нет — сервер их и так игнорирует, но
 * и слать незачем; пустые продолжения не шлём; фото — только загруженные (у них есть id).
 */
export function publishBody(draft, { kind, topic, parentId }) {
  const body = { text: draft.text.trim() }
  if (kind === 'comment') {
    body.parentId = parentId
  } else {
    body.topic = topic
    const continuations = draft.parts.map((p) => p.trim()).filter(Boolean)
    if (continuations.length) body.continuations = continuations
  }
  const mediaIds = readyMediaIds(draft)
  if (mediaIds.length) body.mediaIds = mediaIds
  return body
}

/** Весь текст ветки одной строкой — копия для подсветки отказа (как в прототипе: основной и продолжения через перевод строки). */
export function fullText(draft) {
  return [draft.text, ...draft.parts]
    .map((p) => p.trim())
    .filter(Boolean)
    .join('\n')
}
```

```js
  } catch {
    // нет места или приватный режим — «Недавние» проживут до перезагрузки
  }
  return next
}
```

```js
// Фото на устройстве перед отправкой (спека 2026-11-11 §7): JPEG не больше 1600 px по длинной стороне, качество 0.85.
// Перерисовка через canvas заодно сбрасывает EXIF с GPS — иначе место съёмки увидели бы все в ленте. Больше 10 МБ
// до сжатия — отказ сразу: такой файл телефон и декодировать будет долго, и сервер его не примет.

export const PHOTO_MAX_BYTES = 10 * 1024 * 1024
export const PHOTO_MAX_SIDE = 1600
export const JPEG_QUALITY = 0.85
// accept для <input type=file>. GIF нет намеренно: GIF в Birge не делаем вовсе (решение владельца, спека §1).
export const PHOTO_ACCEPT = 'image/jpeg,image/png,image/webp,image/heic,image/heif,.heic,.heif'

const PHOTO_TYPES = /^image\/(jpeg|png|webp|heic|heif)$/i

export class PhotoError extends Error {
  constructor(code) {
    super(code)
    this.name = 'PhotoError'
    // too_big | not_image | heic | decode
    this.code = code
  }
}

/** HEIC с iPhone: тип у файла бывает пустым — тогда узнаём по расширению. */
export function isHeic(file) {
  return /^image\/hei[cf]$/i.test(file?.type || '') || /\.(heic|heif)$/i.test(file?.name || '')
}

/** Отказ до сжатия: не фото — not_image, больше 10 МБ — too_big; иначе null. */
export function checkPhoto(file) {
  if (!file) return 'not_image'
  if (!PHOTO_TYPES.test(file.type || '') && !isHeic(file)) return 'not_image'
  if (file.size > PHOTO_MAX_BYTES) return 'too_big'
  return null
}

/** Размер после сжатия: длинная сторона не больше max, пропорции те же, маленькое не растягиваем. */
export function fitWithin(width, height, max = PHOTO_MAX_SIDE) {
  const long = Math.max(width, height)
  if (!long || long <= max) return { width, height }
  const k = max / long
  return { width: Math.max(1, Math.round(width * k)), height: Math.max(1, Math.round(height * k)) }
}

function loadImage(file) {
  const url = URL.createObjectURL(file)
  return new Promise((resolve, reject) => {
    const img = new Image()
    img.onload = () => resolve(img)
    img.onerror = () => reject(new Error('decode'))
    img.src = url
  }).finally(() => URL.revokeObjectURL(url))
}

// createImageBitmap поворачивает по EXIF-ориентации. Где он файл не открыл (HEIC в части Safari) — через <img>:
// Safari и iOS декодируют им HEIC, и ориентацию современные браузеры там тоже применяют.
async function decodeInBrowser(file) {
  if (typeof createImageBitmap === 'function') {
    try {
      const bitmap = await createImageBitmap(file, { imageOrientation: 'from-image' })
      return { source: bitmap, width: bitmap.width, height: bitmap.height, close: () => bitmap.close?.() }
    } catch {
      // ниже — запасной путь через <img>
    }
  }
  const img = await loadImage(file)
  return { source: img, width: img.naturalWidth, height: img.naturalHeight, close: () => {} }
}

async function encodeInBrowser(source, width, height, quality) {
  const canvas = document.createElement('canvas')
  canvas.width = width
  canvas.height = height
  const ctx = canvas.getContext('2d')
  // Белая подложка: прозрачный PNG в JPEG иначе получил бы чёрный фон.
  ctx.fillStyle = '#fff'
  ctx.fillRect(0, 0, width, height)
  ctx.drawImage(source, 0, 0, width, height)
  const blob = await new Promise((resolve) => canvas.toBlob(resolve, 'image/jpeg', quality))
  if (!blob) throw new Error('encode')
  return blob
}

/**
 * Фото → { blob, width, height } (JPEG). Ошибки — PhotoError: too_big и not_image — до декодирования, heic — HEIC в
 * браузере, который его не открывает (подсказка «сохраните как JPG»), decode — всё прочее.
 * decode / encode подменяются в тестах: в jsdom нет ни декодера картинок, ни canvas.
 */
export async function shrinkPhoto(file, { decode = decodeInBrowser, encode = encodeInBrowser } = {}) {
  const refused = checkPhoto(file)
  if (refused) throw new PhotoError(refused)
  let image
  try {
    image = await decode(file)
  } catch {
    throw new PhotoError(isHeic(file) ? 'heic' : 'decode')
  }
  try {
    const size = fitWithin(image.width, image.height)
    const blob = await encode(image.source, size.width, size.height, JPEG_QUALITY)
    return { blob, width: size.width, height: size.height }
  } catch {
    throw new PhotoError('decode')
  } finally {
    image.close?.()
  }
}
```

```js
// Подсветка найденного в копии отклонённого текста (спека 2026-11-11 §3.3, §7). Сервер отдаёт hits так, как их
// написал ученик («х@й», а не нормализованное «хай»), поэтому ищем их в исходном тексте буквально; регистр — любой.
// Отдаём куски, а не HTML: их рисует React, и текст ученика никогда не попадает в разметку — экранирование делает
// сам React, dangerouslySetInnerHTML здесь не нужен вовсе.

const escapeRe = (s) => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')

/** Текст → [{ text, mark }]: mark — найденный фрагмент. Длинные находки раньше коротких: «блядь» целиком, а не «бля». */
export function highlightParts(text, hits) {
  const source = typeof text === 'string' ? text : ''
  if (!source) return []
  const words = [...new Set((Array.isArray(hits) ? hits : []).filter((h) => typeof h === 'string' && h.trim()))].sort(
    (a, b) => b.length - a.length,
  )
  if (!words.length) return [{ text: source, mark: false }]
  const re = new RegExp(words.map(escapeRe).join('|'), 'giu')
  const parts = []
  let last = 0
  for (const m of source.matchAll(re)) {
    if (m.index > last) parts.push({ text: source.slice(last, m.index), mark: false })
    parts.push({ text: m[0], mark: true })
    last = m.index + m[0].length
  }
  if (last < source.length) parts.push({ text: source.slice(last), mark: false })
  return parts
}
```

Create `src/birge/outcome.js`:

```js
import { reasonKey } from './labels.js'

// Что увидит ученик после «Опубликовать» — таблица §3.3 спеки 2026-11-11. Чистая функция: форма только рисует.
// tone — цвет плашки (ok | warn | bad); clear — очистить ли поле: отказ оставляет текст, его переписывают.
// Поля escalated в ответе ученику нет (ёмкость очереди — внутреннее дело модерации) — и не читаем его.

const TONE = { published: 'ok', hidden: 'ok', pending: 'warn', tomorrow: 'warn', feedback: 'warn', rejected: 'bad' }

const BASE = { vars: {}, message: null, removedMediaIds: [], post: null, reasons: [], risk: null, hits: [], feedback: false, feedbackId: null }

/** Сколько минут ждать после 429 (§3.7): вверх и не меньше одной; без retryAfterSec — минута. Общее у публикации и фото. */
export function retryMinutes(err) {
  return Math.max(1, Math.ceil((err?.retryAfterSec ?? 60) / 60))
}

/** Ответ POST /mobile/birge/posts (PublishResponse, §5.3) → что показать. Неизвестное решение — как сбой. */
export function publishOutcome(res) {
  const decision = res?.decision
  const tone = TONE[decision]
  if (!tone) return failureOutcome(null)
  const post = res.post ?? null
  switch (decision) {
    // hidden — переполнение лимита в режиме «скрыто»: автор видит пост как опубликованный (карточка приходит со
    // status: 'published'), и ответ ему тот же (§3.3)
    case 'published':
    case 'hidden':
      return { ...BASE, tone, clear: true, post, titleKey: 'birge.res.published.title', textKey: 'birge.res.published.text' }
    case 'pending':
      return { ...BASE, tone, clear: true, post, titleKey: 'birge.res.pending.title', textKey: 'birge.res.pending.text' }
    case 'tomorrow':
      return { ...BASE, tone, clear: true, post, titleKey: 'birge.res.tomorrow.title', textKey: 'birge.res.tomorrow.text' }
    // Обращение сервер уже создал: оставь мы текст в поле, повторная отправка задвоила бы его (§3.3)
    case 'feedback':
      return {
        ...BASE,
        tone,
        clear: true,
        feedback: true,
        feedbackId: res.feedbackId ?? null,
        titleKey: 'birge.res.feedback.title',
        textKey: 'birge.res.feedback.text',
      }
    default: {
      const codes = (Array.isArray(res.reasons) ? res.reasons : []).map((r) => r?.code)
      return {
        ...BASE,
        tone,
        clear: false,
        // Повтор с теми же mediaIds сервер примет — вложения своего автоотклонённого поста он переносит в новый;
        // удалённые проверкой (IMAGE_UNSAFE) он перечисляет, их форма и убирает (§4 «Медиа»).
        removedMediaIds: Array.isArray(res.removedMediaIds) ? res.removedMediaIds.filter((id) => Number.isFinite(id)) : [],
        titleKey: 'birge.res.rejected.title',
        textKey: 'birge.res.rejected.rewrite',
        reasons: [...new Set(codes.map(reasonKey))],
        risk: Number.isFinite(res.risk) ? res.risk : null,
        hits: Array.isArray(res.hits) ? res.hits.filter((h) => typeof h === 'string' && h) : [],
      }
    }
  }
}

/**
 * Ответа с решением нет: 429 — «Слишком часто — через N мин» (§3.7), 400 — текст сервера, остальное — общая ошибка.
 * Текст в поле остаётся.
 */
export function failureOutcome(err) {
  const fail = { ...BASE, tone: 'bad', clear: false, titleKey: 'birge.res.notPublished' }
  if (err?.status === 429) return { ...fail, textKey: 'birge.res.rateLimit', vars: { n: retryMinutes(err) } }
  // 400 — отказ проверки запроса (§5.1, например «Напишите хотя бы пару слов»): у сервера точный текст, показываем его.
  if (err?.status === 400 && err.serverMessage) return { ...fail, textKey: null, message: err.serverMessage }
  return { ...fail, textKey: 'birge.res.error' }
}
```

```js
// Шаги проверки под формой, пока идёт запрос публикации (спека 2026-11-11 §7, прототип .pipe/.step). Шаги — витрина
// того, что делает сервер (§3.1); настоящего хода проверки ответ не сообщает, поэтому они тикают по таймеру, а ответ
// закрывает оставшиеся. Шаг фото — только когда фото есть.

export const STEP_MS = 550

export function checkSteps(photoCount) {
  return [
    ...(photoCount > 0 ? [{ id: 'photo', key: 'birge.step.photo', vars: { n: photoCount } }] : []),
    { id: 'dict', key: 'birge.step.dict', vars: {} },
    { id: 'ai', key: 'birge.step.ai', vars: {} },
    { id: 'rules', key: 'birge.step.rules', vars: {} },
  ]
}

/**
 * Состояние шагов: по одному в такт; последний крутится, пока нет ответа (закрыть его раньше — значит соврать, что
 * проверка кончилась); пришёл ответ — закрыты все.
 */
export function stepStates(total, tick, finished) {
  const running = Math.min(tick, total - 1)
  return Array.from({ length: total }, (_, i) => {
    if (finished) return 'done'
    if (i < running) return 'done'
    return i === running ? 'run' : 'wait'
  })
}
```

```js
// Как показать пост ученику (спека 2026-11-11 §7). Чистые функции под карточкой.

/** Бейдж своего непубличного поста. Чужое непубличное ученику и не приходит (§5.1), поэтому у чужих бейджа нет. */
export function postBadge(post) {
  if (!post?.mine) return null
  if (post.status === 'pending' || post.status === 'tomorrow') return { key: 'birge.badge.review', tone: 'pend' }
  if (post.status === 'rejected') return { key: 'birge.badge.rejected', tone: 'rej' }
  // Скрытое по переполнению сервер отдаёт автору как published (§3.3). Если всё же пришёл hidden/overflow — без бейджа:
  // автор не должен узнать о подмене.
  if (post.status === 'hidden' && post.hiddenReason !== 'overflow') return { key: 'birge.badge.hidden', tone: 'hid' }
  return null
}

/**
 * Лайк — только у опубликованного: на остальное сервер ответит отказом (§5.1). Скрытый по переполнению пост автору
 * приходит как published — у него лайк работает.
 */
export const isLive = (post) => post?.status === 'published'

/** Жалоба — не на свой пост и только пока сервер её разрешает (canReport: уже жаловался — false). */
export const canReport = (post) => Boolean(post && !post.mine && post.canReport)

export function authorInitial(author) {
  const name = (author?.name || '').trim()
  return name ? Array.from(name)[0].toUpperCase() : '?'
}

const LOCALES = { ru: 'ru-RU', kk: 'kk-KZ', en: 'en-GB' }
const dayOf = (date, timeZone) =>
  new Intl.DateTimeFormat('en-CA', { timeZone, year: 'numeric', month: '2-digit', day: '2-digit' }).format(date)

/**
 * Время у карточки, как в прототипе: сегодня — «09:40», вчера — словом, раньше — «1 нояб.». Зона — браузера
 * (timeZone: undefined); в тестах её задают явно.
 */
export function postTime(iso, { lang = 'ru', now = new Date(), timeZone, yesterday = 'Вчера' } = {}) {
  if (!iso) return ''
  const date = new Date(iso)
  if (Number.isNaN(date.getTime())) return ''
  const locale = LOCALES[lang] || LOCALES.ru
  const day = dayOf(date, timeZone)
  if (day === dayOf(now, timeZone)) {
    return new Intl.DateTimeFormat(locale, { timeZone, hour: '2-digit', minute: '2-digit' }).format(date)
  }
  if (day === dayOf(new Date(now.getTime() - 86400000), timeZone)) return yesterday
  return new Intl.DateTimeFormat(locale, { timeZone, day: 'numeric', month: 'short' }).format(date)
}
```

```jsx
import { useState } from 'react'
import { useI18n } from '../i18n.jsx'
import { CATEGORY_KEY, DEFAULT_CATEGORY, ECAT, categories, emojisOf } from './emoji.js'

/**
 * Панель смайликов (прототип: вкладки категорий, заголовок, сетка 9 в ряд). После выбора не закрывается — смайлики
 * часто ставят по нескольку подряд; закрывают её кнопка смайлика в форме, Esc или фокус в поле ввода.
 */
export default function EmojiPanel({ recent, onPick, onClose }) {
  const { t } = useI18n()
  const tabs = categories(recent)
  const [chosen, setChosen] = useState(DEFAULT_CATEGORY)
  // «Недавние» могли опустеть или ещё не появиться — тогда открыты «Эмоции».
  const current = tabs.includes(chosen) ? chosen : DEFAULT_CATEGORY
  const label = (name) => t(`birge.emoji.cat.${CATEGORY_KEY[name]}`)

  return (
    <div
      className="brg-pop"
      role="dialog"
      aria-label={t('birge.compose.emoji')}
      onKeyDown={(e) => {
        if (e.key === 'Escape') onClose?.()
      }}
    >
      <div className="brg-ecats" role="tablist">
        {tabs.map((name) => (
          <button
            key={name}
            type="button"
            role="tab"
            aria-selected={current === name}
            aria-label={label(name)}
            title={label(name)}
            className={current === name ? 'is-on' : ''}
            onClick={() => setChosen(name)}
          >
            {ECAT[name]}
          </button>
        ))}
      </div>
      <div className="brg-etitle">{label(current)}</div>
      <div className="brg-emo">
        {emojisOf(current, recent).map((emoji, i) => (
          <button
            key={`${current}-${i}`}
            type="button"
            // Кнопка не забирает фокус из поля: на телефоне иначе прыгала бы клавиатура на каждом смайлике.
            onMouseDown={(e) => e.preventDefault()}
            onClick={() => onPick(emoji)}
          >
            {emoji}
          </button>
        ))}
      </div>
    </div>
  )
}
```

```jsx
import { useEffect, useLayoutEffect, useRef, useState } from 'react'
import { useI18n } from '../i18n.jsx'
import { publishBirgePost, uploadBirgeMedia } from './birgeApi.js'
import { DEFAULT_TOPIC, TOPICS } from './labels.js'
import {
  TEXT_MAX,
  canAddPart,
  canPublish,
  counter,
  emptyDraft,
  fullText,
  insertAt,
  photoSlots,
  photosUploading,
  publishBody,
  tooShort,
} from './draft.js'
import { readRecent, rememberEmoji } from './emoji.js'
import { PHOTO_ACCEPT, shrinkPhoto } from './photo.js'
import { STEP_MS, checkSteps, stepStates } from './steps.js'
import { failureOutcome, publishOutcome, retryMinutes } from './outcome.js'
import { highlightParts } from './highlight.js'
import EmojiPanel from './EmojiPanel.jsx'
import { PhotoIcon, SmileIcon } from './icons.jsx'

const PHOTO_ERROR = {
  too_big: 'birge.photo.tooBig',
  not_image: 'birge.photo.notImage',
  heic: 'birge.photo.heic',
  decode: 'birge.photo.decode',
}

function initialOf(name) {
  const s = (name || '').trim()
  return s ? Array.from(s)[0].toUpperCase() : '?'
}

// Автовысота поля, как в прототипе: высота по содержимому. scrollHeight 0 бывает у скрытого поля — тогда не трогаем,
// иначе поле схлопнулось бы в ноль.
function grow(el) {
  if (!el) return
  el.style.height = 'auto'
  if (el.scrollHeight) el.style.height = `${el.scrollHeight}px`
}

function Counter({ text }) {
  const c = counter(text)
  return c.show ? <span className={`brg-cnt${c.over ? ' is-over' : ''}`}>{c.len}/{TEXT_MAX}</span> : null
}

function Outcome({ outcome, copy, onOpenFeedback }) {
  const { t } = useI18n()
  const parts = outcome.hits.length && copy ? highlightParts(copy, outcome.hits) : []
  return (
    <div className={`brg-res brg-res--${outcome.tone}`} role="status">
      <b>{t(outcome.titleKey)}</b>
      {outcome.reasons.length > 0 && (
        <p>{t('birge.res.rejected.reasons', { reasons: outcome.reasons.map((key) => t(key)).join(', '), risk: outcome.risk ?? '—' })}</p>
      )}
      {parts.length > 0 && (
        <p className="brg-res__copy">
          {parts.map((part, i) => (part.mark ? <mark key={i}>{part.text}</mark> : <span key={i}>{part.text}</span>))}
        </p>
      )}
      <p>{outcome.message ?? t(outcome.textKey, outcome.vars)}</p>
      {outcome.feedback && onOpenFeedback && (
        <button type="button" className="brg-link" onClick={() => onOpenFeedback(outcome.feedbackId)}>
          {t('birge.res.feedback.open')}
        </button>
      )}
    </div>
  )
}

/**
 * Форма «Новая ветка» (kind="thread") и ответа в ветке (kind="comment") — один редактор, как в прототипе; у ответа
 * нет темы и продолжений. Фото пережимается и уходит на проверку сразу при выборе (§3.1); пока запрос публикации
 * идёт — шаги проверки, затем итог по таблице §3.3 (outcome.js).
 */
export default function Composer({ kind = 'thread', token, authorName, parentId = null, onPublished, onOpenFeedback }) {
  const { t } = useI18n()
  const thread = kind === 'thread'
  const [draft, setDraft] = useState(emptyDraft)
  const [topic, setTopic] = useState(DEFAULT_TOPIC)
  // Последняя позиция курсора: field -1 — основное поле, 0..3 — продолжение. Смайлик встаёт сюда.
  const [caret, setCaret] = useState({ field: -1, pos: null })
  const [pop, setPop] = useState(false)
  const [recent, setRecent] = useState(() => readRecent())
  // Ошибка фото — ключ словаря и подстановки: у 429 в тексте минуты ожидания.
  const [photoError, setPhotoError] = useState(null)
  const [busy, setBusy] = useState(false)
  const [steps, setSteps] = useState(null)
  const [tick, setTick] = useState(0)
  const [finished, setFinished] = useState(false)
  const [outcome, setOutcome] = useState(null)
  // Копия отправленного текста для подсветки отказа: поле к тому времени ученик мог уже начать править.
  const [copy, setCopy] = useState('')
  const mainRef = useRef(null)
  const partRefs = useRef([])
  const focusPart = useRef(null)
  const seq = useRef(0)
  const shrinking = useRef(0)
  const previews = useRef(new Set())

  // Превью фото — объектные URL; уходя с экрана, отпускаем их, иначе картинки висят в памяти вкладки.
  useEffect(() => {
    const urls = previews.current
    return () => {
      urls.forEach((url) => URL.revokeObjectURL(url))
      urls.clear()
    }
  }, [])

  useLayoutEffect(() => {
    partRefs.current.length = draft.parts.length
    grow(mainRef.current)
    partRefs.current.forEach(grow)
  }, [draft.text, draft.parts])

  // «Дополните ветку» сразу ставит курсор в новое продолжение — как в прототипе.
  useEffect(() => {
    if (focusPart.current == null) return
    partRefs.current[focusPart.current]?.focus()
    focusPart.current = null
  }, [draft.parts.length])

  // Шаги тикают, пока ждём ответа (прототип: по 550 мс на шаг).
  useEffect(() => {
    if (!busy || finished) return undefined
    const id = setInterval(() => setTick((n) => n + 1), STEP_MS)
    return () => clearInterval(id)
  }, [busy, finished])

  const setField = (field, value) =>
    setDraft((d) => (field < 0 ? { ...d, text: value } : { ...d, parts: d.parts.map((p, i) => (i === field ? value : p)) }))
  const track = (field) => (e) => setCaret({ field, pos: e.target.selectionStart })

  function pickEmoji(emoji) {
    const field = caret.field >= 0 && caret.field < draft.parts.length ? caret.field : -1
    const current = field < 0 ? draft.text : draft.parts[field]
    const next = insertAt(current, field === caret.field ? caret.pos : null, emoji)
    if (!next) return
    setField(field, next.text)
    setCaret({ field, pos: next.pos })
    setRecent(rememberEmoji(emoji, recent))
  }

  function forget(url) {
    URL.revokeObjectURL(url)
    previews.current.delete(url)
  }

  function dropPhoto(key, preview) {
    forget(preview)
    setDraft((d) => ({ ...d, photos: d.photos.filter((p) => p.key !== key) }))
  }

  async function addPhotos(files) {
    setPhotoError(null)
    // Фото, которые ещё пережимаются, места не заняли, но займут — иначе два быстрых выбора дали бы пятое фото.
    const room = photoSlots(draft) - shrinking.current
    if (files.length > room) setPhotoError({ key: 'birge.photo.tooMany' })
    for (const file of files.slice(0, Math.max(0, room))) {
      shrinking.current += 1
      let shrunk
      try {
        shrunk = await shrinkPhoto(file)
      } catch (err) {
        setPhotoError({ key: PHOTO_ERROR[err?.code] || 'birge.photo.decode' })
        continue
      } finally {
        shrinking.current -= 1
      }
      seq.current += 1
      const key = `p${seq.current}`
      const preview = URL.createObjectURL(shrunk.blob)
      previews.current.add(preview)
      setDraft((d) => ({ ...d, photos: [...d.photos, { key, preview, status: 'uploading', id: null }] }))
      // Фото уходит на проверку сразу (§3.1): пока ученик дописывает текст, сервер его уже посмотрел.
      uploadBirgeMedia(token, shrunk.blob, 'photo.jpg')
        .then((res) => {
          if (res?.id == null) throw new Error('нет id вложения')
          setDraft((d) => ({ ...d, photos: d.photos.map((p) => (p.key === key ? { ...p, status: 'ready', id: res.id } : p)) }))
        })
        .catch((err) => {
          // Загрузки фото — под тем же антиспамом, что публикации (§3.7): на 429 — «через N мин», а не «не удалось».
          setPhotoError(
            err?.status === 429 ? { key: 'birge.res.rateLimit', vars: { n: retryMinutes(err) } } : { key: 'birge.photo.uploadFailed' },
          )
          dropPhoto(key, preview)
        })
    }
  }

  function addPart() {
    if (!canAddPart(draft)) return
    focusPart.current = draft.parts.length
    setDraft((d) => ({ ...d, parts: [...d.parts, ''] }))
  }

  function removePart(i) {
    setDraft((d) => ({ ...d, parts: d.parts.filter((_, j) => j !== i) }))
    setCaret({ field: -1, pos: null })
  }

  async function publish() {
    if (busy || !canPublish(draft, kind)) return
    const sent = draft
    setPop(false)
    setBusy(true)
    setFinished(false)
    setTick(0)
    setOutcome(null)
    setSteps(checkSteps(sent.photos.length))
    setCopy(thread ? fullText(sent) : sent.text.trim())
    let result
    try {
      result = publishOutcome(await publishBirgePost(token, publishBody(sent, { kind, topic, parentId })))
    } catch (err) {
      result = failureOutcome(err)
      // Ответа с решением нет — проверки не было, и шаги «проверено» врали бы.
      setSteps(null)
    }
    setFinished(true)
    setOutcome(result)
    setBusy(false)
    // После отказа фото годятся для повтора (вложения отклонённого поста сервер переносит); убираем только удалённые
    // проверкой (removedMediaIds).
    const removed = new Set(result.removedMediaIds)
    const gone = result.clear ? sent.photos : sent.photos.filter((p) => removed.has(p.id))
    gone.forEach((p) => forget(p.preview))
    if (result.clear) {
      setDraft(emptyDraft())
      setCaret({ field: -1, pos: null })
    } else if (gone.length) {
      setDraft((d) => ({ ...d, photos: d.photos.filter((p) => !removed.has(p.id)) }))
    }
    if (result.post) onPublished?.(result.post)
  }

  const states = steps ? stepStates(steps.length, tick, finished) : []
  const initial = initialOf(authorName)
  const placeholder = t(thread ? 'birge.compose.placeholder' : 'birge.compose.replyPlaceholder')
  const noPhotoRoom = busy || photoSlots(draft) === 0

  return (
    <section className={`brg-card brg-composer${thread ? '' : ' brg-composer--reply'}`}>
      <div className="brg-cw">
        <div className="brg-cl" aria-hidden="true">
          <span className="brg-av">{initial}</span>
          {thread && (
            <>
              <span className="brg-vline" />
              <span className="brg-av brg-av--xs">{initial}</span>
            </>
          )}
        </div>
        <div className="brg-cr">
          <div className="brg-who">
            <b>{authorName}</b>
            {thread && (
              <>
                <span className="brg-who__sep" aria-hidden="true">
                  ›
                </span>
                <select aria-label={t('birge.compose.topic')} value={topic} disabled={busy} onChange={(e) => setTopic(e.target.value)}>
                  {TOPICS.map((key) => (
                    <option key={key} value={key}>
                      {t(`birge.topic.${key}`)}
                    </option>
                  ))}
                </select>
              </>
            )}
          </div>
          <div className="brg-field">
            <textarea
              ref={mainRef}
              rows={1}
              maxLength={TEXT_MAX}
              value={draft.text}
              readOnly={busy}
              placeholder={placeholder}
              aria-label={placeholder}
              onChange={(e) => {
                setField(-1, e.target.value)
                track(-1)(e)
              }}
              onClick={track(-1)}
              onKeyUp={track(-1)}
              onFocus={() => setPop(false)}
            />
            <Counter text={draft.text} />
          </div>
          {draft.photos.length > 0 && (
            <div className="brg-mrow">
              {draft.photos.map((p, i) => (
                <div key={p.key} className={`brg-mitem${p.status === 'uploading' ? ' is-loading' : ''}`}>
                  <img src={p.preview} alt={t('birge.card.photo', { n: i + 1 })} />
                  <button type="button" className="brg-x" aria-label={t('birge.compose.removePhoto')} disabled={busy} onClick={() => dropPhoto(p.key, p.preview)}>
                    ×
                  </button>
                </div>
              ))}
            </div>
          )}
          <div className="brg-tools">
            <label className={`brg-tool${noPhotoRoom ? ' is-off' : ''}`} title={t('birge.compose.photo')}>
              <PhotoIcon />
              <input
                type="file"
                hidden
                multiple
                accept={PHOTO_ACCEPT}
                aria-label={t('birge.compose.photo')}
                disabled={noPhotoRoom}
                onChange={(e) => {
                  // Список копируем до сброса value: сброс нужен, чтобы то же фото можно было выбрать снова.
                  const files = Array.from(e.target.files || [])
                  e.target.value = ''
                  addPhotos(files)
                }}
              />
            </label>
            <button
              type="button"
              className={`brg-tool${pop ? ' is-on' : ''}`}
              title={t('birge.compose.emoji')}
              aria-label={t('birge.compose.emoji')}
              aria-expanded={pop}
              disabled={busy}
              onClick={() => setPop((v) => !v)}
            >
              <SmileIcon />
            </button>
            {pop && <EmojiPanel recent={recent} onPick={pickEmoji} onClose={() => setPop(false)} />}
          </div>
          {photoError && (
            <p className="brg-error" role="alert">
              {t(photoError.key, photoError.vars)}
            </p>
          )}
          {thread &&
```

Create `src/birge/usePostActions.js`:

```js
import { useCallback, useRef } from 'react'
import { useI18n } from '../i18n.jsx'
import { reportBirgePost, setBirgeLike } from './birgeApi.js'

/**
 * Лайк и жалоба — одни у ленты и у ветки. Лайк ставится сразу (оптимистично), затем число берётся из ответа сервера:
 * параллельные лайки других учеников могли его сдвинуть. Отказ возвращает прежнее. Жалоба одна на пост (§3.4):
 * после неё кнопка уходит, а повтор (409) значит «уже жаловался».
 * update(id, patch) — поправить пост в своём списке; remove(id) — убрать (жалобы скрыли пост).
 */
export function usePostActions({ token, update, remove, onToast }) {
  const { t } = useI18n()
  // Второй клик по тому же лайку, пока первый в пути, перевернул бы его обратно не дождавшись сервера.
  const pending = useRef(new Set())

  const like = useCallback(
    async (post) => {
      if (pending.current.has(post.id)) return
      pending.current.add(post.id)
      const liked = !post.liked
      update(post.id, { liked, likes: Math.max(0, (post.likes ?? 0) + (liked ? 1 : -1)) })
      try {
        const res = await setBirgeLike(token, post.id, liked)
        if (res && typeof res.liked === 'boolean') update(post.id, { liked: res.liked, likes: Number(res.likes) || 0 })
      } catch {
        update(post.id, { liked: Boolean(post.liked), likes: post.likes ?? 0 })
        onToast?.(t('birge.like.failed'))
      } finally {
        pending.current.delete(post.id)
      }
    },
    [token, update, onToast, t],
  )

  const report = useCallback(
    async (post) => {
      try {
        const res = await reportBirgePost(token, post.id, null)
        update(post.id, { canReport: false })
        // Пост скрылся после жалоб — у остальных его больше нет, убираем и у пожаловавшегося.
        if (res?.hidden) remove?.(post.id)
        onToast?.(t(res?.hidden ? 'birge.report.hidden' : 'birge.report.sent'))
      } catch (err) {
        if (err?.status === 409) {
          update(post.id, { canReport: false })
          onToast?.(t('birge.report.already'))
        } else {
          onToast?.(t('birge.report.failed'))
        }
      }
    },
    [token, update, remove, onToast, t],
  )

  return { like, report }
}
```

```jsx
import { useCallback, useEffect, useRef, useState } from 'react'
import { useI18n } from '../i18n.jsx'
import { isSectionMissing, listBirgePosts } from './birgeApi.js'
import { TOPICS } from './labels.js'
import Composer from './Composer.jsx'
import PostCard from './PostCard.jsx'
import { usePostActions } from './usePostActions.js'

/**
 * Лента (спека 2026-11-11 §7): форма «Новая ветка» сверху, фильтр тем (Все + пять), карточки, подгрузка по курсору.
 * 404 первой страницы — бэкенд без раздела: отдаём экрану onMissing, он пишет «Раздел скоро откроется».
 */
export default function Feed({ token, authorName, onOpen, onMissing, onToast, onOpenFeedback }) {
  const { t } = useI18n()
  const [topic, setTopic] = useState(null)
  const [items, setItems] = useState([])
  const [cursor, setCursor] = useState(null)
  const [state, setState] = useState('loading')
  // Форма появляется после первой удачной загрузки и дальше не пропадает: смена темы не должна стирать черновик,
  // а при 404 формы не было вовсе.
  const [opened, setOpened] = useState(false)
  const [loadingMore, setLoadingMore] = useState(false)
  const generation = useRef(0)
  const sentinel = useRef(null)
  const moreRef = useRef(null)
  // onMissing в ref: экран может передать новую функцию на каждом рендере, и перезапрашивать ленту из-за этого незачем.
  const missingRef = useRef(onMissing)
  useEffect(() => {
    missingRef.current = onMissing
  })

  const update = useCallback((id, patch) => setItems((list) => list.map((p) => (p.id === id ? { ...p, ...patch } : p))), [])
  const remove = useCallback((id) => setItems((list) => list.filter((p) => p.id !== id)), [])
  const { like, report } = usePostActions({ token, update, remove, onToast })

  // Поколение запроса: ответ старой темы, пришедший после новой, ленту не перезаписывает.
  const loadFirst = useCallback(
    async (nextTopic) => {
      generation.current += 1
      const mine = generation.current
      setState('loading')
      setItems([])
      setCursor(null)
      try {
        const page = await listBirgePosts(token, { topic: nextTopic })
        if (mine !== generation.current) return
        setItems(page.items)
        setCursor(page.nextCursor)
        setState('ready')
        setOpened(true)
      } catch (err) {
        if (mine !== generation.current) return
        if (isSectionMissing(err)) missingRef.current?.()
        else setState('error')
      }
    },
    [token],
  )

  useEffect(() => {
    loadFirst(topic)
  }, [loadFirst, topic])

  async function loadMore() {
    if (!cursor || loadingMore) return
    const mine = generation.current
    setLoadingMore(true)
    try {
      const page = await listBirgePosts(token, { topic, cursor })
      if (mine !== generation.current) return
      // Новый пост за это время сдвинул ленту — карточка могла прийти второй раз.
      setItems((list) => [...list, ...page.items.filter((p) => !list.some((x) => x.id === p.id))])
      setCursor(page.nextCursor)
    } catch {
      if (mine === generation.current) onToast?.(t('birge.loadError'))
    } finally {
      if (mine === generation.current) setLoadingMore(false)
    }
  }

  useEffect(() => {
    moreRef.current = loadMore
  })

  // Подгрузка при прокрутке; кнопка под лентой остаётся — для клавиатуры и браузеров без наблюдателя.
  useEffect(() => {
    const el = sentinel.current
    if (!el || typeof IntersectionObserver === 'undefined') return undefined
    const io = new IntersectionObserver(
      (entries) => {
        if (entries.some((e) => e.isIntersecting)) moreRef.current?.()
      },
      { rootMargin: '400px 0px' },
    )
    io.observe(el)
    return () => io.disconnect()
  }, [cursor, state])

  // Свой новый пост — сверху, если подходит под выбранную тему: сервер вернул карточку целиком (§5.3).
  const addPost = useCallback(
    (post) => {
      if (topic && post.topic !== topic) return
      setItems((list) => [post, ...list.filter((p) => p.id !== post.id)])
    },
    [topic],
  )

  return (
    <>
      {opened && <Composer kind="thread" token={token} authorName={authorName} onPublished={addPost} onOpenFeedback={onOpenFeedback} />}
      <section className="brg-card brg-feed">
        <div className="brg-filters" role="group" aria-label={t('birge.filter.label')}>
          <button type="button" className={`brg-chip${topic ? '' : ' is-on'}`} aria-pressed={!topic} onClick={() => setTopic(null)}>
            {t('birge.filter.all')}
          </button>
          {TOPICS.map((key) => (
            <button key={key} type="button" className={`brg-chip${topic === key ? ' is-on' : ''}`} aria-pressed={topic === key} onClick={() => setTopic(key)}>
              {t(`birge.topic.${key}`)}
            </button>
          ))}
        </div>
        {state === 'loading' && (
          <p className="brg-empty" role="status">
            {t('birge.loading')}
          </p>
        )}
        {state === 'error' && (
          <p className="brg-empty" role="alert">
            {t('birge.loadError')}{' '}
            <button type="button" className="brg-link" onClick={() => loadFirst(topic)}>
              {t('birge.retry')}
            </button>
          </p>
        )}
        {state === 'ready' && items.length === 0 && <p className="brg-empty">{t('birge.empty')}</p>}
        {state === 'ready' && items.map((post) => <PostCard key={post.id} post={post} onOpen={(p) => onOpen(p.id)} onLike={like} onReport={report} />)}
        {state === 'ready' && cursor && (
          <div className="brg-morerow" ref={sentinel}>
            <button type="button" className="brg-btn brg-btn--ghost" disabled={loadingMore} onClick={loadMore}>
              {t(loadingMore ? 'birge.loading' : 'birge.more')}
            </button>
          </div>
        )}
      </section>
    </>
  )
}
```

```jsx
import { useCallback, useEffect, useState } from 'react'
import { useI18n } from '../i18n.jsx'
import { getBirgeThread } from './birgeApi.js'
import Composer from './Composer.jsx'
import PostCard from './PostCard.jsx'
import { usePostActions } from './usePostActions.js'

/**
 * Ветка (спека 2026-11-11 §7): «← Все ветки», пост, комментарии с отступом, форма ответа — тот же редактор без темы
 * и продолжений. Ответить можно только на опубликованную ветку: на остальные сервер ответит 409 (§5.1).
 */
export default function Thread({ token, postId, authorName, onBack, onToast, onOpenFeedback }) {
  const { t } = useI18n()
  const [thread, setThread] = useState(null)
  const [comments, setComments] = useState([])
  const [state, setState] = useState('loading')
  const [version, setVersion] = useState(0)

  useEffect(() => {
    let alive = true
    setState('loading')
    getBirgeThread(token, postId).then(
      (data) => {
        if (!alive) return
        if (!data.thread) {
          setState('missing')
          return
        }
        setThread(data.thread)
        setComments(data.comments)
        setState('ready')
      },
      (err) => {
        if (alive) setState(err?.status === 404 ? 'missing' : 'error')
      },
    )
    return () => {
      alive = false
    }
  }, [token, postId, version])

  const update = useCallback((id, patch) => {
    setThread((p) => (p && p.id === id ? { ...p, ...patch } : p))
    setComments((list) => list.map((c) => (c.id === id ? { ...c, ...patch } : c)))
  }, [])

  // Жалобы скрыли саму ветку — читать дальше нечего, назад в ленту; скрытый комментарий просто уходит.
  const remove = useCallback(
    (id) => {
      if (id === postId) onBack?.()
      else setComments((list) => list.filter((c) => c.id !== id))
    },
    [postId, onBack],
  )

  const { like, report } = usePostActions({ token, update, remove, onToast })

  // Свой ответ — в конец; счётчик ветки считает только опубликованные (§4), поэтому «на проверке» его не двигает.
  const addComment = useCallback((post) => {
    setComments((list) => [...list, post])
    if (post.status === 'published') setThread((p) => (p ? { ...p, comments: (p.comments ?? 0) + 1 } : p))
  }, [])

  return (
    <>
      <button type="button" className="brg-back" onClick={onBack}>
        {t('birge.thread.back')}
      </button>
      {state === 'loading' && (
        <p className="brg-card brg-empty" role="status">
          {t('birge.loading')}
        </p>
      )}
      {state === 'missing' && (
        <p className="brg-card brg-empty" role="alert">
          {t('birge.thread.missing')}
        </p>
      )}
      {state === 'error' && (
        <p className="brg-card brg-empty" role="alert">
          {t('birge.thread.loadError')}{' '}
          <button type="button" className="brg-link" onClick={() => setVersion((v) => v + 1)}>
            {t('birge.retry')}
          </button>
        </p>
      )}
      {state === 'ready' && thread && (
        <>
          <section className="brg-card brg-thread">
            <PostCard post={thread} onLike={like} onReport={report} />
            {comments.length > 0 ? (
              comments.map((c) => <PostCard key={c.id} post={c} comment onLike={like} onReport={report} />)
            ) : (
              <p className="brg-empty">{t('birge.thread.noComments')}</p>
            )}
          </section>
          {thread.status === 'published' ? (
            <Composer kind="comment" token={token} authorName={authorName} parentId={thread.id} onPublished={addComment} onOpenFeedback={onOpenFeedback} />
          ) : (
            <p className="brg-hint brg-closed">{t('birge.thread.closed')}</p>
          )}
        </>
      )}
    </>
  )
}
```

```jsx
import { useCallback, useEffect, useRef, useState } from 'react'
import LearningLayout from '../components/LearningLayout.jsx'
import { useI18n } from '../i18n.jsx'
import Feed from '../birge/Feed.jsx'
import Thread from '../birge/Thread.jsx'
import RulesCard from '../birge/RulesCard.jsx'
import { writePostParam } from '../birge/postParam.js'

/**
 * Just to Study Birge — лента веток студентов (спека docs/superpowers/specs/2026-11-11-birge-community-design.md §7).
 * Оболочка — кабинетная (LearningLayout): меню и общий колокольчик уведомлений, своего у раздела нет. Лента или ветка
 * переключаются внутри экрана; открытая ветка держится в ?post=, чтобы её пережил F5 и открыла ссылка.
 *
 * target — цель перехода из App: { postId, at }. at различает два перехода к одной цели: уведомление, пришедшее,
 * пока экран открыт, App не пересоздаёт, а меняет target; postId: null — пункт меню, назад в ленту.
 */
export default function BirgePage({ token, userName, userLevel, onNav, onProfile, target = null }) {
  const { t } = useI18n()
  const [postId, setPostId] = useState(target?.postId ?? null)
  const [missing, setMissing] = useState(false)
  const [toast, setToast] = useState('')
  const lastTarget = useRef(target?.at ?? null)
  const rootRef = useRef(null)

  useEffect(() => {
    if (!target || target.at === lastTarget.current) return
    lastTarget.current = target.at
    setPostId(target.postId ?? null)
  }, [target])

  useEffect(() => {
    writePostParam(postId)
  }, [postId])
  // Уходя с экрана, ?post= снимаем: общая синхронизация адреса в App о нём не знает и оставила бы его чужому экрану.
  useEffect(() => () => writePostParam(null), [])

  useEffect(() => {
    if (!toast) return undefined
    const id = setTimeout(() => setToast(''), 2600)
    return () => clearTimeout(id)
  }, [toast])

  const open = useCallback((id) => {
    setPostId(id)
    rootRef.current?.scrollIntoView?.({ block: 'start' })
  }, [])
  const back = useCallback(() => setPostId(null), [])
  const markMissing = useCallback(() => setMissing(true), [])
  const openFeedback = useCallback((feedbackId) => onNav?.('feedback', feedbackId != null ? { feedbackId } : undefined), [onNav])
  const authorName = (userName || '').trim() || t('birge.compose.you')

  return (
    <LearningLayout userName={userName} userLevel={userLevel} token={token} active="birge" onNav={onNav} onProfile={onProfile}>
      <div className="brg" ref={rootRef}>
        <header className="brg-top">
          <h1>{t('birge.title')}</h1>
          <p>{t('birge.subtitle')}</p>
        </header>
        {missing ? (
          <section className="brg-card brg-soon">
            <h2>{t('birge.soon.title')}</h2>
            <p>{t('birge.soon.text')}</p>
          </section>
        ) : (
          <div className="brg-grid">
            <div className="brg-main">
              {postId != null ? (
                <Thread
                  key={postId}
                  token={token}
                  postId={postId}
                  authorName={authorName}
                  onBack={back}
                  onToast={setToast}
                  onOpenFeedback={openFeedback}
                />
              ) : (
                <Feed token={token} authorName={authorName} onOpen={open} onMissing={markMissing} onToast={setToast} onOpenFeedback={openFeedback} />
              )}
            </div>
            <RulesCard />
          </div>
        )}
        {toast && (
          <div className="brg-toast" role="status">
            {toast}
          </div>
        )}
      </div>
    </LearningLayout>
  )
}
```

```bash
WORK=$(mktemp -d)

// Переносит в старый src/theme-dark.generated.css только тёмные правила Birge из полного нового вывода генератора.
import { readFileSync, writeFileSync } from 'node:fs'

const [oldFile, newFile, outFile] = process.argv.slice(2)
const read = (f) => readFileSync(f, 'utf8').replace(/\r\n/g, '\n')
const HEAD = /^\/\* {2}(.+?\.css) {2}\*\/$/gm
const blocks = (css) => {
  const heads = [...css.matchAll(HEAD)]
  return heads.map((m, i) => ({ name: m[1], start: m.index, end: i + 1 < heads.length ? heads[i + 1].index : css.length }))
}

const fresh = read(newFile)
const freshBlocks = blocks(fresh)
let out = read(oldFile)

for (const name of ['birge.css', 'mobile/birge.css']) {
  const i = freshBlocks.findIndex((b) => b.name === name)
  if (i < 0) {
    console.log(`${name}: цветовых правил нет — блок не нужен`)
    continue
  }
  if (blocks(out).some((b) => b.name === name)) throw new Error(`${name} уже есть в старом файле`)
  const next = freshBlocks.slice(i + 1).map((b) => b.name).find((n) => blocks(out).some((b) => b.name === n))
  const at = next ? blocks(out).find((b) => b.name === next).start : out.length
  out = out.slice(0, at) + fresh.slice(freshBlocks[i].start, freshBlocks[i].end) + out.slice(at)
  console.log(`${name}: вставлен перед ${next ?? 'концом файла'}`)
}

const svc = freshBlocks.find((b) => b.name === 'services.css')
const rule = fresh.slice(svc.start, svc.end).match(/html\[data-theme="dark"\] \.svc-tile__new \{[\s\S]*?\n\}\n/)
if (!rule) throw new Error('в новом блоке services.css нет правила .svc-tile__new')
if (!out.includes('.svc-tile__new')) {
  const old = blocks(out).find((b) => b.name === 'services.css')
  out = out.slice(0, old.end) + rule[0] + out.slice(old.end)
  console.log('services.css: добавлено .svc-tile__new')
}
writeFileSync(outFile, out)
MERGE_BIRGE_DARK
node "$WORK/merge.mjs" "$WORK/old.css" "$WORK/new.css" src/theme-dark.generated.css
git diff --numstat src/theme-dark.generated.css
```

```js
/** Лента и фото; publish(body) → { status?, reply } — ответ публикации. Возвращает тела отправленных публикаций. */
async function mockBirge(page, { publish = () => ({ reply: decision({ decision: 'published' }) }), list = json({ items: [card()], nextCursor: null }) } = {}) {
  const sent = []
  await page.route(LIST, (route) => {
    const req = route.request()
    if (req.method() !== 'POST') return route.fulfill(list)
    const body = req.postDataJSON()
    sent.push(body)
    const { status = 200, reply } = publish(body)
    return route.fulfill(json(reply, status))
  })
  await page.route(MEDIA, (route) => route.fulfill(json({ id: 7, width: 1, height: 1 })))
  return sent
}
```
