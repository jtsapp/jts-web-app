# Казахская добавка к словарю распознавания (Soniox context.terms).
#
# Достаётся ТОЛЬКО сессиям казахоязычных тьюторов — KZ_SPEAKING_TUTORS в
# agent.py (Спарк, KZ-стенд, Айзере). Луна и Декстер её не получают: по-казахски
# они не говорят, а русскую речь их учеников подсказки тянули бы в казахскую.
#
# Зачем. Жалоба тестера 24.09.2026: «атыңыз» распознаётся как «аты» — суффикс
# срезан. Казахский агглютинативный, слово растёт цепочкой суффиксов, и на
# неоднозначном звуке распознавание выбирает короткую частую форму. Здесь —
# формы, которые ученик реально говорит тьютору: вежливое «сіз» (-ыңыз/-іңіз,
# -сыз/-сіз, просьбы на -ңызшы) и «мен» о себе.
#
# Это ПОДСКАЗКА, а не ограничение словаря: сказать можно любое слово, просто
# перечисленные получают вес на неоднозначном звуке. Поэтому список короткий:
# лишние строки размывают вес нужных и тянут шум в перечисленные слова.
#
# Замер 25.09.2026 (синтез Soniox TTS + розовый шум 0 дБ, 126 клипов, конфиг
# websocket как у плагина): формы из списка 78% → 93%, соседние формы, которых
# в списке нет, 75% → 83%; голые «аты/жасы» суффиксом не обросли, английский и
# русский без изменений. Работает в основном сам список: без него одна строка
# general даёт 85%. Цена — английское слово посреди казахской фразы изредка
# уходит в кириллицу («Импров» вместо «Improve»): 1 из 22. На чистом синтезе
# разницы нет — его Soniox и так распознаёт без ошибок, жалоба про живую речь.
#
# Формат как у stt-terms.txt: одно слово или выражение в строке, решётка —
# комментарий. Читается на СТАРТЕ ВОРКЕРА: после правки нужен `lk agent deploy`.
# Откат без деплоя — секрет воркера SONIOX_STT_CONTEXT_KK=off.
#
# Путь двойной: <repo-root>/data/stt-terms-kk.txt в дев-режиме и
# agent/stt-terms-kk.txt внутри Docker-образа. Копии держать синхронными —
# test_stt_context.py сверяет их побайтно.
